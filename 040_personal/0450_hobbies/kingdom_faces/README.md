# kingdom_faces — 顔画像

- 出典: キングダム Fandom Wiki（https://kingdom.fandom.com）の各キャラクター記事のポートレート画像。
  アニメ各シリーズの立ち絵／原作コマ。**著作権は原作・アニメ制作各社に帰属**するため、
  **著作権は原泰久／集英社および各アニメ製作委員会に帰属。**
  2026-08-24 に公開へ切り替え（Kyo判断）。ページ側にクレジットを記載し、
  260823_kingdom.html には `noindex, noarchive` を設定している。
- 対応表: `face_map.json`（node id → 記事タイトル / ファイル名 / 取得URL）
- 生成手順: `dl/` に元画像を置き `python3 crop.py` で 220x220 の顔クロップを生成。
  クロップがずれる場合は `crop_overrides.json` に
  `"<node id>": [一辺(画像高に対する割合), 中心X(幅に対する割合), 上端Y(高に対する割合)]` を追記して再実行。
- ページ側（260823_kingdom.html）は画像が無ければ頭文字アバターに自動フォールバックする。
  画像を非公開に戻したい場合は、この 97 枚を `git rm --cached` して .gitignore に戻せば
  公開ページは頭文字表示に戻る（ただし git 履歴には残る）。
