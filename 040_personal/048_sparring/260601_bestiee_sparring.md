## 5. Kyo の所感 — 構造課題

### ① 営業先の分散・Recurring 不在
- スポット案件の積み上げで毎月新規開拓の負荷が累積
- 学生は毎年入れ替わる前提 → **同じスポンサーから継続発注**（年次パッケージ／半期契約／プレミアム枠）は取れるはず
- Recurring 化が利益率と再現性の両方を引き上げる

### ② ICP：売上1,000億級メガベン
- レバレジーズ・DeNA・サイバーエージェント クラス
- 新卒採用に投資余力があり、繰り返し買ってくれる顧客像
- 4社×継続契約で売上予測可能性が一気に上がる

### ③ 後藤代表の DM 営業依存・属人性
- 現状：後藤代表が自ら DM で営業 → **非効率 × 完全属人化**
- CEO の時間が枯渇 → North Star と矛盾
- 営業オペ標準化（SDR / CSM / アカウント分担）が必要

### ★④ 勝負は「戦略」ではなく「実行スピード × 脱属人化」
- 事業構造はシンプル。**真っ直ぐやり切れば月営利800万は到達可能**
- 難所は「何を売るか」ではなく、**どれだけ早く・どれだけ後藤代表に依存しない状態で**到達するか
- 意思決定の評価軸は2つだけ：
  - **Time-to-North-Star**（到達までの時間）
  - **Non-Founder Replicability**（創業者非依存の再現性）

### ⑤ Telme（学生向け面接練習AI）の収益化が詰まっている
- 学生向け AI 面接練習サービスを持つが、**売上への転換が難しい**
- 学生は WTP が低く、無料代替（ChatGPT・YouTube）も豊富
- 現状マネタイズの主軸にできていない
- 論点：
  1. そもそも **B2C 課金で攻める価値があるか**（5億 M&A シナリオの主役にはなり得ない）
  2. **B2B転換** — 大学キャリアセンター／予備校／企業の内定者フォローツールへの卸
  3. **採用イベントの "副産物" として無料配布** — データ取得・コミュニティ滞留の装置として位置付け（収益でなくアセット化として評価）
  4. 主役にならないなら **リソース投下を絞る判断** も検討

### ★⑥ 想定とのズレ：実態は "ハイクラス" なのに、見え方が "その他大勢のイベント" になっている
- **実態：** 東大早慶を中心に良質な学生は確実に集められている（プロダクトとしては機能している）
- **見え方：** ワンキャリア・サポーターズ・各種就活フェス等と同カテゴリに並べられ、**「採用イベント会社」**としてしか見られていない

**ギャップが生む損失：**
1. **単価が下がる** — コモディティ価格に引っ張られる（「定数」化の根本原因）
2. **反復契約に繋がらない** — 差別化が伝わらないので "今期も1回スポット" で終わる
3. **M&Aマルチプル** が "イベント会社"（3〜5x）に収まり、"ハイクラス人材プラットフォーム"（10〜20x）にならない

**ズレの発生源（仮説）：**
- イベント名（フェス／MEETUP）が一般用語で記憶に残らない
- "選抜" の基準・学生プロファイルが **外部から見えない**（数値・属性・学生個人の魅力が露出していない）
- 採用成果（実際の内定・入社件数・年収レンジ）が **開示されていない**
- 東大王ブランドが "イベント集客" にのみ使われ、**プロダクト価値の証明** に使われていない

**打ち手の方向性：** 「イベント」というカテゴリから降りる。出方を変える（"招待制クラブ" / "選抜共同体" / "タレントレジストリ" 等の上位概念で語り直す）

### ★⑦ ランチ会のマッチング相手がズレている — 起業家×起業家 ではなく 起業家×優秀な学生
- 現在、ランチ会の場で **起業家同士** が出会う設計になっている
- だが、参加企業（採用投資余力のあるメガベン・起業家）が **本当に会いたいのは "優秀な学生"** のはず

**ズレが起きている理由（仮説）：**
- 後藤代表の人脈の "近さ" で起業家を呼ぶのが楽（属人ネットワークの再利用）
- 学生を集めるオペコストの方が高い／不確実
- 「起業家コミュニティ」っぽい絵面が見栄えする

**是正すると効くこと：**
1. **顧客価値が跳ね上がる** — 起業家からすれば "他の起業家と飯" はいくらでもあるが、"厳選された優秀学生と1時間" は希少
2. **スポンサー単価の根拠** ができる — 学生1人あたり◯円という明確な値付け
3. **bestiee 唯一の供給**＝"優秀な学生のフロー" を毎回ステージに乗せられる
4. **アセットが厚くなる** — 学生×企業の接点ログが残る（タレントグラフの素材）

**論点：** なぜ今、"本来売れる商品"（起業家×学生）ではなく "売りやすい商品"（起業家×起業家）になっているのか？ ここに脱属人化と PMF の根本がある。

### ★⑧ M&A をゴールに据えるなら「残るアセット」を逆算
- 5x × 5億円の M&A 前提 → 買い手から見て**クロージング後も残るアセット**が必要
- 営利だけの「人で回した稼ぐ装置」は買い叩かれる
- 残せるアセット候補：
  1. **東大早慶のタレントプール / コミュニティ会員DB**（再販可能な母集団）
  2. **反復契約の年次スポンサー枠**（売上の予測可能性）
  3. **イベント運営 SOP**（属人ノウハウの形式知化）
  4. **Telme 等のプロダクト資産**（コード・モデル・データ）
- 後藤代表の脳内にしか無いものは資産として残らない
- → **「持続可能な運営」=「アセット化された運営」** として再定義

## 6. Hard Side — どちらが制約資源か（マーケットプレイス理論）

> 2サイドのうち、必ず片側が "ハードサイド"。bestiee の制約資源は **優秀な学生**。

| サービス | EASY（簡単な側） | **HARD（制約資源）** |
|---|---|---|
| Tinder | 男性 | **可愛い女性** |
| Uber | 乗客 | **ドライバー** |
| Airbnb | ゲスト | **良質なホスト／物件** |
| **bestiee** | 採用企業（メガベン・起業家） | **優秀な学生** |

### ハードサイドが学生だと認めると、すべてが反転する

1. **経営リソース配分** — 後藤代表の時間の **80%以上を "学生獲得・維持・コミュニティ化" に投下する**のが本来の正解。企業営業は副次
2. **北極星指標の置き換え** — 「スポンサー件数／月次売上」から **「Active 学生数／学生 NPS／学生 LTV（複数回参加率）」** へ。売上は学生プールの厚みの関数として後からついてくる
3. **Telme の再定義** — 「収益化が詰まる SaaS」ではなく **"優秀な学生を引きつけ・滞留させるフック"**。無料で配って学生データ・行動ログを取り、ハードサイドを厚くする装置
4. **ランチ会の組替え（★⑦と直結）** — 起業家×起業家ランチは "易しい側" 同士の社交。**毎回どんなに少人数でも "優秀な学生1人" をハブにする設計**に変える
5. **絞り込みの優先順位** — 次節の Variable Drill-down では、まず **「どんな学生を集めるか」を1〜2象限に絞り切る**。企業側の絞り込みはその後で連鎖的に決まる
6. **M&A時のアセット価値** — 買い手が払うのは "学生プールへの独占アクセス" であって、 "スポンサー契約のキャッシュフロー" ではない。**ハードサイドの厚み = 企業価値の本体**

## 7. Meta Q — 今「定数」だと思っているもののうち、本当は「変数」になりうるものは何か？

> いまの事業モデルが暗黙に固定しているパラメータを洗い出す。動かせるものを動かすと、月営利800万・5億M&Aの上限が変わる可能性。

| 定数（暗黙に固定しているもの） | 現在値 | 変数化したら何が変わるか |
|---|---|---|
| スポンサー単価 | 40万 / 150万 | プレミアム枠・優先送客・年次契約を束ねれば単価 2〜3倍。価格は需要側 WTP に対して低い説 |
| スポンサー社数 / イベント | 4社 | 6〜8社にしたとき、企業側の "学生1人あたり面談時間" が薄まる閾値はどこか |
| 開催頻度 | 小:月6回 / 大:Q1回 | 頻度↑＝学生枯渇／オペ限界が先。学生プールサイズが本当の制約変数 |
| 学生の対象大学 | 東大早慶 | 医学部・海外大・地方旧帝に広げれば母集団数倍。ブランド希薄化とのトレードオフ |
| 収益源 | スポンサーフィーのみ | 成功報酬／学生課金（Telme等）／データ販売を載せると同じ集客で売上が乗算化 |
| 営業チャネル | 後藤代表のDM | SDR代行 / 紹介ネットワーク / イベント営業会社との提携。CEO以外で売れる経路 |
| 買い手の想定 | 未定（5億M&A） | レバ・DeNA・サイバー vs ベネフィット・パーソル・リクルート。買い手でアセット要件が変わる |
| マルチプル | 5x（営利） | "イベント会社" 評価＝3〜5x、"プラットフォーム/SaaS" 評価＝10〜20x。見せ方で着地額2〜4倍ぶれる |
| 事業の本籍 | 新卒採用イベント | "ハイクラス若者コミュニティ" として捉え直せば出口は新卒採用に限らない（VC紹介・教育商材） |
| 後藤代表の関与時間 | ほぼ100% | **変数化が最優先**。50%→20% に下げるロードマップ自体が "M&Aレディ" の定義 |

## 8. Variable Drill-down — 学生属性 × 新卒入社先属性

> 現状「東大早慶」という大学だけのフィルタにとどまり、学生属性と新卒入社先属性が広い。**この2軸を絞り切ることが、ポジショニング・単価・反復契約・M&Aマルチプル すべてに同時に効く最大レバー。**

絞ることで得られるもの：
- 「⚪︎⚪︎なら bestiee」と単独想起されるブランド
- 希少性に基づく高単価の根拠
- 学生集客の基準・コミュニティの一貫性
- 特定セグメントで圧倒的なタレントグラフ＝M&Aアセット

### ① 学生属性の軸
| 軸 | 値の例 |
|---|---|
| 大学 | 東大 / 京大 / 早稲田 / 慶應 / 一橋 / 東工大 / 海外大 |
| 学年・段階 | 学部1-2 / 3-4 / 修士 / 博士 |
| 専攻 | AI・ML / 理系全般 / 経済 / 法 / 医 / 文系 |
| 志向 | 起業 / 外資 / メガベン / 大手 / 研究 / 公共 |
| 能力・経験 | 国際オリンピック級 / 研究室トップ / 起業経験 / 海外経験 / 体育会 |
| 人格 | 成長志向 / 即戦力志向 / 尖り / バランス |

### ② 新卒入社先（買い手）の軸
| 軸 | 値の例 |
|---|---|
| 業種 | 外資コンサル / 投資銀行 / PE・VC / メガベン / スタートアップ / 外資テック / 大手事業会社 |
| フェーズ | プレシード / シード / シリーズA-C / 上場メガベン / 伝統大企業 |
| 役割 | PM / ML・エンジニア / 投資 / 戦略 / セールス / 創業者直下 |
| 報酬レンジ | 〜500万 / 500-800 / 800-1500 / 1500万+ |
| ロケーション | 東京 / 大阪 / SF / NY / SG / ロンドン |
| 採用者属性 | 東大OB起業家 / 外資出身創業者 / 伝統メガベンHR / CxO直接 |

### 絞り込み候補（強い順 / Kyo 仮説）

| # | コンセプト | 希少性 | M&A倍率 | 単価 | オペ難度 |
|---|---|---|---|---|---|
| **A** | **東大早慶 × AI/ML系院生 × 創業者直下スタートアップ** | ★★★★★ | 10-20x | 高 | 中 |
| B | 東大早慶 × 起業志向 × 上場前スタートアップ創業者直下 | ★★★★ | 8-15x | 高 | 中 |
| C | 東大早慶 × 外資志向 × 外資コンサル/IB/テック | ★★ | 3-5x | 中 | 高（競合） |
| D | 東大早慶 × 全方位 × 全方位（**現状**） | ★ | 3-5x | 低 | 高（分散） |

**A** 最も希少・最も単価が立つ象限。「AIネイティブ世代の最高峰」を一気通貫で押さえる。bestieeの東大ブランド × Telmeの相性も最大。M&A時は "AI人材プラットフォーム" として 10x+ マルチプル狙える。

**B** 「将来の起業家・経営者」をターゲットに、シリーズA-Cの創業者に最短距離で繋ぐ。後藤代表のネットワークと最も親和性が高い。買い手は VC・メガベン・1982インパクトファンド 等の "次世代経営者発掘" 系。

**C** 既存のONE CAREER・外資就活ドットコム等とガチンコ競合。報酬レンジは最も高いが、競合過密。bestieeが取りに行く理由は薄い。

**D** 現状の暗黙ポジショニング。差別化が成立せず、ワンキャリア／サポーターズと同列のイベント会社に見える。M&Aマルチプル 3〜5x で天井。

### 意思決定の問い
A〜C のどれを「bestiee の本籍」に据えるか？ 一度決めれば、**イベント設計／学生集客チャネル／スポンサー営業先／プロダクト（Telme機能）／買い手シミュレーション**の全てが連鎖的に決まる。逆に "全部" を維持すると、どの軸でも勝てない。**絞り切る = 全変数を同時にレバレッジする最大の意思決定**。
