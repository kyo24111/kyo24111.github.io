Term DB

リサーチ系ページに出てくる用語の統合辞書。science / industry / market / finance などが混ざるので、Field と sub で分類している。

  1. 各ページの Terms タブ、またはこの表で ✓ を入れる → known（理解済み）
  2. known の語は、全ページの本文で英語に置き換わる（例：「electrical conductivityは銀に次いで2位」）。hover で元の日本語
  3. ✓ はまずこのブラウザに保存される。Sync to DB を押すと GitHub の terms_known.js に commit され、1〜2分後に全端末の標準になる（初回だけ GitHub token を入力）
