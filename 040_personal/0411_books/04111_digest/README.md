# Book Digest（簡易版記事）運用ルール

Kyoが本を入れる → Claudeがリサーチして簡易版記事を作る → 気になったら実際に買って読む。

## 発動
チャットで「本: <書名>」「この本の digest 作って」など。書名だけでOK。

## 手順
1. **特定**：書名で検索し、著者・出版社・発売日・ISBNを確定。同名・類似タイトルが複数あれば、最新／話題の方を採用し、報告で他候補も一言添える。
2. **リサーチ**（公開情報のみ）
   - 出版社ページ：内容紹介・目次・著者紹介
   - 試し読み（はじめに・序章）
   - 書評・読書ブログ（2〜3本）、著者インタビュー／対談
   - 洋書なら原書の review・著者の講演も
3. **記事を作る**：`YYMMDD_<slug>.html`（既存の `261120_america_b_side.html` をテンプレにする）
   - **TL;DR**：判定（買い／拾い読み／見送り＋理由）・3行で・向く/向かない・読むならこの順・評判
   - **Main**：どんな本か・著者・章ごとの要点
   - **Terms**：英語term＋日本語＋1〜2行説明
   - **Sources**：読んだURL一覧＋確認日
4. **一覧に1行足す**：`index.html` の `DIGESTS` 配列の先頭へ（status は `未購入`）。
5. `python3 gen_breadcrumbs.py`（リポジトリ直下）→ commit & push（公開repo）。

## 書き方の約束
- 章の中身は **`本書` ラベル（公開情報で確認できたこと）と `背景` ラベル（本の外の一般知識で補った予習）を分ける**。本文未読の部分を本書の主張として書かない。
- 推測は「（推測）」と明記。
- 引用は短く（1文以内）。本文の長い転載はしない（公開repoのため）。
- 個人的な事情（購入理由の私的な文脈など）は書かない。公開ページ。

## 読んだ後
- 買ったら `status` を `購入`、読み終えたら `読了` に。
- 本棚（`../books.html`）に入れるかは別判断。
