## 幼少期・学生時代

### 幼少期（保育園〜4歳）

- **しんあい保育園**（小金井市）
- 母が前後と抱っこで3兄弟を自転車1台で移動するのが日常
- 母のフライト中は多摩センターの母方祖父母宅に頻繁に預けられる（ディズニー・ムシキングに夢中）
- **七田式**を母に毎日やってもらっていた（今の記憶力の原型かもしれない）
- 保育園はよく休んでいた

### 5歳：朝練スタート

- 父・兄と毎朝6時に公園で朝練。1年でオフはほぼなし
- この習慣が後の競技力と早起き体質の原点
- 小1で **50m 9.7秒**。足が速く体力・運動神経ともに突出

### 小学校低学年（小金井二小）

**野球**
- 小学校野球チーム「小金井ビクトリー」に入団
- 小2から小3の試合に **2番キャッチャーのレギュラー**で出場
- 1学年上の先輩は後に一中野球部の仲間にも

**習い事**
- 水泳・柔道・野球・ピアノ。野球以外はやる気なし
- ピアノは金曜夕方で苦痛だったが音感の原点に。柔道は父の武士道精神で強制入会、4〜5年継続

**勉強**
- 父とホワイトボードで毎晩勉強会（算数・国語・英語）
- 日能研模試を小2から受験。この学習貯金は高校卒業まで続いた

**エピソード**
- 初めて好きな子ができる（インドア系・笑顔可愛い・字が綺麗）
- クラスメイトの森くんと殴り合いの喧嘩 → 父（武士道・弱いものいじめ大嫌い）と一緒に謝りに行く
- 小3：ライオンズマンションから小金井公園の一軒家へ引っ越し（鈴木貫太郎家がスロベニア移住のため1年仮住まい）
  - 鈴木貫太郎：数学系YouTuber、ヨビノリと仲がいい。奥様は外務省勤務。貫太郎が専業主夫。握る寿司が相当うまい。息子2人も非常に優秀。

### 小学校高学年

- 小4：地下室付きの新しい一軒家に引っ越し（6000万円・30年ローン。父の誇らしげな顔が今も鮮明）
- 地下室で毎晩深夜までゲーム → 朝6時朝練 → 学校で寝る、という生活
- 駄菓子屋こまち、仙川・小金井公園の秘密基地（廃棄電子レンジを椅子に火遊び）

**ゲーム**
- メダルゲームは統計で台を選ぶほどガチった
- デュエマ・桃鉄・モンハン・パズドラを「**他を叩きのめすまでやめない**」スタイルでやりこんだ
- ゲームが戦略立案・言語化・PDCA思考を鍛えた

**恋バナ**
- クラス男子間で暗号をつけた手紙を回す文化。自分のコードネームの子（ピーマン）を小6まで好きだった

**メタ認知の急成長**
- 嫌い/好きのベクトルを嗅ぎ分ける力が育ち、いじめ撲滅の緩衝材として機能し始める
- 小中高を通じて自分のコミュニティに一切いじめがなかった —「**陰の支配者**」としての自覚が芽生える
- 同クラスの中島くん（→開成→東大、姉も桜蔭）と中学入試問題でバトル。SAPIXなしでも地頭で引けを取らなかった

### 中学（小金井一中）

**野球部全体**
- 顧問：社会の佐藤先生（当時28歳・めちゃくちゃ怖い）
- 朝練毎日・年間オフ4〜5日・夏休みは7〜19時
- 都内の中学のうち50校が自分のエリアに割り当てられ、そのうち2校が都大会に行けるシステム。春夏秋 **8回中4回出場**（早稲田実業中等と対戦）
- 中三：東京都西地区選抜20人に選出（**5番ショート**）
- 同学年9人のうち3人が16歳からタバコ・薬・歌舞伎町に足を踏み入れた仲間たち。「頭の良さ以外の大事さ」を体で学んだ
- リーダーシップスタイル：部活＝キャプテン、体育祭＝委員長、クラス＝黒幕。ポジションによって使い分けた

**中1**
- クラス崩壊（担任が鬱で不登校 → 授業ボイコット → 3年生の怖い先生が怒鳴って収拾）
  - 自分は端から俯瞰して「生徒のアクションに対して教員がどう反応するか」を関数の入出力のように観察していた
- 人生初の彼女（ピーマン・2013年6月18日・12歳・誕生日2日違い）
  - 夏にディズニーへ。電車で肩に寄りかかって寝た感覚を「あの経験はあれ以来二度とない」と今も振り返る
  - ソフト部で週3〜4は一緒に下校
- パズドラ全盛期（ホルス・サクヤの時代）。テスト前は貫井北町図書館でゲーム
- 数学・英語は無双。社会・理科は最下位クラス

**中2**
- クラスメイトが中学の屋上から飛び降り自殺（授業中に発生）
  - 本町小から不登校だった彼が屋上から飛び降り
  - シングルマザーの母親の背中、女性担任・福田先生の涙、葬式へ向かう際の小池先生との会話が今も鮮明
  - その後2年D組にはカウンセラーが常時同席することになった
  - もし時を戻せるなら話を聞いてみたい。この複雑な体験が自分を強くしてくれたのは間違いない

**中3**
- 体育祭委員長。「学年1位ではなく歴代記録更新」を目標に設定
  - 運動が苦手な女子を朝6時に公園に呼んで朝練
  - 怒鳴らず・遅刻を注意せず・楽しませることに全集中するボトムアップ指揮で不満ゼロ
  - ムカデ競争で**学校記録更新** → 看板に自分の名前とクラスが載った瞬間のドーパミンは今でも鮮明
- 「戦略を立て・人を動かし・難しいミッションを・チームで・長期で・解く」ことへの快感の関数がここで調整された
- 定期テストの個人競技には興味がなかった
