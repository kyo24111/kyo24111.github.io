## ディレクトリ構成

```
AI-PROJECTS/
├── 01_business_ideas/      # 新規事業・会社設立のアイデア
├── 02_corporate_mgmt/      # 会社経営全般
│   ├── projects/           # AIコンサル案件（案件ごとにサブフォルダ）
│   ├── finance/            # 会社の財務・決算
│   └── administration/     # 経営管理・法務・組織
├── 03_research/            # 市場調査・技術リサーチ
│   ├── science/            # サイエンス
│   ├── legend/             # 偉人（起業家・経営者・政治家）
│   ├── startup/            # 企業（資金調達・グロース・事件）
│   └── geo-history/        # 地理・歴史
├── 04_personal/            # 個人の人生全般
│   ├── travel/             # 旅行計画・記録
│   ├── finance/            # 個人資産管理
│   ├── diary/              # 日記・思考ログ
│   └── hobbies/            # 趣味（ポーカー・チェス・Catanなど）
└── README.md               # このファイル
```
