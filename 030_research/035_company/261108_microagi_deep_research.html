microagi、ロボットを作らないロボット会社

Created: 2026-11-08 ／ Last updated: 2026-11-08
microagi（独ミュンヘン、2025年創業）は、人の作業を一人称カメラと手袋で録ってロボットの学習データにする会社。データを集める「Shift」（2万人超・15か国）でフロンティアラボにデータを売り、工場には「Atlas」で市販のロボットを追加学習させてリースする。創業者は元Red Bull Racing（F1）の空力エンジニア Bercan Kilic。2026年7月に独史上最大のシード $55M、10月には「Shift開始から6か月で年換算売上 $100M超」と自己申告した。

01In One Line
「ロボットに人の手の動かし方を教える教材」を世界中の人から買い集め、AI研究所に売りつつ、工場にはロボットごと貸し出すドイツの会社。ロボットも基盤モデルも自分では作らない。データ（Shift）で稼ぎ、導入（Atlas）で囲う二本立てで、Mecka と並ぶ「人のデータ」側の急成長株。
02Robot Data 101

そもそも「ロボットの学習データ」とは

ChatGPTはネット上の文章で学べたが、ロボットの「手をどう動かすか」のデータはネットにほとんど無い。だから誰かが新しく作る必要がある。作り方は大きく2つ。

種類取り方長所短所主な会社
Human action data（人のデータ）人がカメラ・手袋をつけて作業安い・量が出る・現場が多様体が違うので変換が要るmicroagi、Mecka、Build AI
Robot action data（ロボットのデータ）人がロボットを遠隔操作して記録ロボットにそのまま使える高い・遅いXDOF、Physical Intelligence

microagi は前者の人のデータを大量に集める会社。ただし、それを売って終わりではなく、自分で工場にロボットを入れるところまでやる点が Mecka などと違う。Mainで詳しく →

05Why It Matters

何がすごいのか

① 伸びる速さ
創業から約1年、Shift 開始から6か月で年換算$100M超（自己申告）。比較に出されるのは Lovable（8か月）や Higgsfield（7か月）
② 集め方がうまい
NYで「無料で家を掃除します、ただし撮影させて」、SFで「無料の出張シェフ」。家庭の中という一番撮りにくい場所のデータを、話題づくりと一緒に取った
③ データと導入の両方を持つ
データ会社（Scale AI型）でも、モデル会社（Physical Intelligence型）でもない。ラボに「データを渡してモデルをもらう」関係を作り、工場への導入で自分の出口も持つ
④ 欧州の製造業という市場
EUの平均年齢は44.9歳、2050年までに働き手が1,880万人減る見込み。ドイツは欧州最大のロボット市場（2024年 約2.7万台設置）。「人が足りない」は工場の経営者にとって切実

06Risks

リスクは何か

① 数字が自己申告だけ
$100Mは「年換算」で、6か月で稼いだ額ではない。データ販売と導入の内訳、継続契約の比率は非公開。顧客名も1社も出ていない
② 人のデータは値崩れしやすい
Build AI が一人称映像100万時間を無償公開するなど、汎用の映像は安くなっている。人に$20/時払うモデルは、単価が下がると利幅が消える
③ プライバシー
家の中・職場を録る事業。EUのGDPR、ドイツの職場の労使協議（従業員代表の同意）など規制が厳しい。「無料掃除はデータ収奪」という批判記事も出た
④ ロボットの実績がまだ無い
Atlas の導入台数・性能・費用対効果は未公表。「動いたら払う」成果報酬は、動かなければ microagi がロボット代を抱える
⑤ 競合が多く、強い
データ供給では Scale AI・Turing・micro1・Mecka、モデルでは Physical Intelligence・Skild AI、ロボットメーカーも自分でデータを取りに来ている（Figure、Tesla）

08Bottom Line (NFA)

結論（筆者の読み、投資助言ではない）

中身は「人のデータの卸」で急成長し、そのお金で「工場へのロボット導入」に賭けている会社。データ側の伸びは Mecka と同じ追い風（ラボがデータを奪い合っている）に乗ったもので、本当の勝負は Atlas が工場で動くかどうか。データの単価は時間とともに下がるので、下がる前に導入の実績に変えられるかが分かれ目。

見るべきは3つ。①Atlas の最初の顧客名と稼働台数、②$100Mの内訳（データ／導入）と継続性、③次のラウンドの評価額とリード（米国の大手VCが入るか）。

「human data はいずれ要らなくなるのでは？」への答え：全部は要らなくならないが、汎用の人の映像は2026〜27年から値崩れする。human が土台・robot が仕上げの分業になりつつあり、microagi の Atlas はその移行への保険。Mainで詳しく →

02Industry: Robot Training Data

なぜ今「ロボットのデータ」にお金が集まるのか

大規模言語モデル（LLM）のときは、材料のテキストはネットにすでにタダであり、お金を生んだのは加工（ラベル付け）をする Scale AI などだった。ロボットは違う。手や体の動かし方のデータは世の中にほとんど存在しない。UC Berkeley の Ken Goldberg 教授は「ロボットがネット規模のデータを持つには10万年かかる」と見積もっている。だから材料そのものを作る会社に価値が出ている。

データの取り方 4分類

分類中身強み弱み主なプレイヤー
① 人の一人称映像カメラ・スマホ・手袋で人の作業を撮る安い・量が出るembodiment gap の変換が要るmicroagi（Shift）、Mecka、Build AI、Human Archive
② テレオペ人がロボットを遠隔操作して実機データを取るロボットにそのまま使える・単価が高い実機とオペレーターが要るXDOF、AgiBot、Tesla・Figureの自社
③ ハンドヘルドロボット型グリッパーを人が持つ①と②の中間専用端末の配布・回収Generalist、Sunday Robotics
④ シミュレーション仮想環境・世界モデルで作る無限に作れる現実とのズレ（sim2real）NVIDIA Cosmos 等

相場観（2026年、各種報道からの目安）

データの種類1時間あたりの単価メモ
未加工の一人称映像$1〜10汎用のものは無償公開が増え、値崩れ中
アノテーション済み・マルチモーダル$15〜50手の姿勢・物体・作業の区切りなどの注釈つき
テレオペ（ロボット実機）$50〜200ロボットにそのまま使える
microagi の位置：撮影者に$20/時払っているので、未加工の映像を$10で売っていたら赤字になる。つまり、手袋のセンサーデータや注釈を足した$15〜50帯以上の「加工済み・マルチモーダル」か、ラボへの独占ライセンスで売っていると読める（筆者の読み）。

関連：Mecka $60M Series B（startup news）／Skild AI $1.4B Series C（startup news）、、Figureはこのフォルダにある。

03Business: Shift & Atlas

二つの事業

Shift — 人の作業データの収集ネットワーク

  • 仕組み：アプリで撮影者（オペレーター）を募り、頭部カメラ（ヘッドストラップ）やセンサー手袋をつけて家事・工場作業を撮ってもらう。報酬は時給約$20＋ボーナス
  • 規模：15か国で2万人超（媒体により1.4万〜2.5万人）。2026年1〜3月だけで1万人超に計$5M超を支払った
  • 売り先：ロボットAIを作るフロンティアラボ。一部は独占ライセンス。プライバシーポリシーには「ロボット学習のためのデータ収集が microagi の事業の中核」と書いてある
  • 個人情報：顔・身分証などはアップロード前にぼかす、と説明
  • US 責任者：Harry Kilberg（Shift US General Manager）。ニューヨークから運営
Column

「無料で家を掃除します、ただし全部撮らせて」

2026-05-28 ニューヨーク

Shift はニューヨークで「信頼できるプロの清掃員が無料で掃除」というキャンペーンを始めた。条件は、清掃員が頭につけたカメラで皿洗い・モップがけ・洗濯物たたみを一人称で録ること。Ars Technica が報じて話題になり、7月にはサンフランシスコで「無料の出張シェフ」を始めた（家にプライベートシェフを無料で呼べる代わりに、調理の様子を録画してロボット用データとして販売。日本語圏では宮武徹郎氏のポストで紹介された）。ロンドン・チューリッヒ・ミュンヘンにも広げる予定。

家庭の中は、ロボットにとって一番データが足りない場所。お金を払って人に撮ってもらうより、「無料サービス」と交換したほうが早く・安く・話題にもなる（筆者の読み）。

同時に、撮影者を集める広告にもなっている（Ars Technica は「本当の目的は、時給$20で撮影してくれる人の募集だろう」と書いた）。

Atlas — 工場へのロボット導入

  • やること：顧客工場で熟練者の作業を録る → ロボットの動かし方（ポリシー）を学習 → 合うハードに載せて動かす。ロボットメーカーにもモデルにも縛られない（hardware- and model-agnostic）
  • モデルの調達：「ラボにデータを渡し、モデルを受け取る」（Kilic）。それを工場ごとのデータでポストトレーニングする。相手のラボ名は非公開
  • ハード：Unitree・UBTech（中国）などから買い、工場にリース。売り切りではない
  • 課金：ロボットが動いたら払う成果報酬（具体的な金額は非公表）
  • 現場常駐：「顧客ごとにエンジニアを現場に置く。いればいるほど、その顧客は競合より少しずつ先に行く」（CTO Nussbaum）
  • 進み具合：データ収集中の顧客が5社、うち1社が生産ラインへの導入準備中（2026-07）。業種は自動車・物流・食品
最初は導入だけの会社だった：Kilic によれば、もともとは導入を本業にするつもりだったが、既存のロボットモデルがどれも出発点として使える水準になかったので、データを集めるために Shift を作った。結果的に Shift のほうが先に大きくなった。

05Financials: The $100M Run Rate

「6か月で$100M」をどう読むか

2026-10-09、CEO Kilic が「Shift 開始から6か月で ARR がゼロから$100Mに」というグラフを投稿した。ただしグラフの脚注は「annualized run rate（年換算売上）」。直近の月の売上を12倍した数字で、6か月間に$100Mを稼いだわけではない。

比較対象$100Mまで数え始め
microagi6か月Shift の開始
Higgsfield AI7か月—
Lovable8か月—
Skild AI10か月最初の商用導入

数え始めの基準が揃っていないので、横並びの比較にはならない（Humanoids Daily）。

筆者の試算（推定）

前提数字
年換算$100M ＝ 月の売上約$8.3M
撮影者への支払い（2026年1〜3月）月約$1.7M ≒ 約8万時間/月
仮にデータを$40/時で売るなら月約21万時間 ≒ 1人月10時間
仮に原価が$20/時なら粗利率は約50%

撮影者2万人・月10時間は無理のない水準で、数字そのものは不可能ではない。ただし、1〜3月の支払いペース（月約8万時間）から6〜9月に2倍以上へ増えた前提になる。また、ラボへの独占ライセンスや一括の大口契約が1つ入るだけで「直近月×12」は大きく膨らむので、継続性は別問題。

生データ（報道ベース）
支払い：Q1 2026 に10,000人超へ計$5M超（Move the Needle）／報酬：$20/時＋ボーナス（Ars Technica 経由）／人数：14,000人超（StartupHub）、20,000人超（TNW・Move the Needle）、25,000人超（Business Insider 経由・Munich Startup）／run rate：$100M超（2026-10-09、Kilic の投稿）

12Key Question: Will Human Data Become Obsolete?

human data はいらなくなるのか

microagi・Mecka の価値を決める一番大事な問い。以下は報道と各社の動きをもとにした筆者の読み。

問い① いま、スタートアップ市場は human / robot どちらに張っているか

答え：両方に大金が入っている。ただし役割が分かれてきた。2025〜26年は、モデルを作る側（買い手）がむしろ human data に寄った年だった。

つまり「human から robot へ乗り換える」というより、human が土台、robot が仕上げという分業になりつつある。

問い② human data はいつ要らなくなるのか

答え：「全部いらなくなる」日は来にくい。ただし「何でもいいから人の映像」は、もう値段がつかなくなり始めている。要らなくなる順番はこう読める。

時期（筆者の読み）価値が落ちるものきっかけ
2026〜27汎用の未加工映像（家事・日常）無償公開（Build AI）・在庫の積み上がり
2027〜29注釈つきの一般的な作業データ世界モデル・合成データの品質向上
2030〜人が集めるデータ全般の比率稼働ロボットが数十万〜百万台規模になり、自分でデータを生む
残り続ける熟練者の技・珍しい作業・失敗例ロボットがまだできないことの「お手本」は人にしか作れない

見るべき3つのシグナル：

  • 稼働台数：現場で動くロボットの稼働時間が、人が集めるデータの時間を超えたら、主役は robot data（自社の稼働ログ）に移る。自動運転で Waymo・Tesla が「自社の車が走るほどデータが増える」状態になったのと同じ
  • 手の形が人に近づくか：ヒューマノイドの手が人の手に近づくほど、人のデータがそのまま使えるようになり、human data の寿命はむしろ延びる。Tesla の自動運転が今も「人の運転」から学んでいるのは、車の操作が人と同じだから
  • データの単価：ラボが払う1時間あたりの単価。汎用の人の映像が$1を切り、テレオペが$100超を保つなら、市場はもう robot 側に評価を移している
microagi にとっての意味：汎用の人の映像（Shift の一部）は時間とともに値崩れする。microagi が工場導入（Atlas）を持つのは、その保険と読める。導入先の工場では、①その現場の熟練者の human data と、②稼働するロボットの robot data の両方が溜まる。つまり「human が要らなくなる時代」にも、自分で robot data を生む側に回れる設計。逆に言えば、Atlas が工場で動かないと、値崩れする側の事業だけが残る。

14Q&A

事業理解のための問答

人の動画で、なぜロボットが動けるようになるのか？
動画から手の位置・指の形・物との接触のタイミングを取り出し、ロボットの関節の動きに置き換える（リターゲティング）。人とロボットは体が違うので完全には写せないが、「何をどの順にやるか」「どこを掴むか」の大まかな知識を大量に入れ、最後に少量のロボット実機データで仕上げる、という使い方が主流。microagi がセンサー手袋を使うのは、映像だけでは分からない指の曲がり・力のかけ方を足すため。
なぜ自社でロボットも基盤モデルも作らないのか？
ロボット本体は中国勢（Unitree 等）が安く作り、基盤モデルはラボが巨額を投じて作る。どちらも microagi が勝てる場所ではない。そのかわり、ラボが欲しいデータと工場の現場という、どちらも持っていないものを押さえる。「データを渡してモデルをもらう」はその交換条件。
「年換算売上（run rate）」と「ARR」は何が違う？
ARR（Annual Recurring Revenue）は継続契約から毎年入る見込みの売上。run rate は直近の月や四半期の売上をそのまま年に引き延ばしたもの。一度きりの大口契約が入った月を12倍すると大きく見える。microagi のグラフは「ARR」と書きつつ脚注は run rate なので、継続性は分からない。
なぜ「成果報酬」にするのか？
工場はロボット導入で何度も失敗してきたので、先にお金を払いたがらない。「動いたら払う」なら導入の判断が早くなる。そのぶん microagi はロボット代と現場のエンジニア代を先に負担するリスクを取る。$55Mの調達で「顧客の導入費用を出す」と言っているのはこのため。
Mecka と比べてどちらが有利？
データの量と売上の規模は同じくらい（どちらも run rate $100M級）。Mecka は Sequoia が付いて米国ラボとの距離が近い。microagi は工場への導入という出口を持つぶん、データの値崩れには強いが、資本を食い、時間もかかる。データ市場が早く成熟する（単価が下がる）ほど microagi の二本立てが効き、データ需要が長く続くほど Mecka の身軽さが効く（筆者の読み）。
