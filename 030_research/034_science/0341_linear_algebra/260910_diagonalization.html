02固有方向をぐるっと探す

ほとんどの向きは、A をかけると向きが変わってしまいます。 でも中には、長さだけ変わって向きが変わらない特別な向きがあります。 それが Av = λv を満たす向き（固有方向）です。 v を1周させて、v と Av が平行になる瞬間を探します。

03固有値を出す — det(A − λI) = 0

アニメで「だいたい45°と135°」と分かりましたが、これを式で正確に出します。

求めたいのは Av = λv かつ v ≠ 0。移項して (A − λI)v = 0。
つまり行列 A − λI が、ゼロでないベクトルをゼロに潰すということ。
潰す ⟺ 面積が0になる ⟺ det(A − λI) = 0。これが固有方程式。
A − λI = 1−λ221−λ det(A − λI) = (1−λ)2 − 4 = λ2 − 2λ − 3 = (λ − 3)(λ + 1) = 0 →   λ1 = 3,   λ2 = −1 検算：和 3 + (−1) = 2 = trace A（対角の和 1+1）／積 3 × (−1) = −3 = det A

04固有ベクトルを出す

λ が分かったら、(A − λI)v = 0 を解くだけです。

λ₁ = 3 :   A − 3I = −222−2 → −2x + 2y = 0 → y = x → v₁ = 11 λ₂ = −1 :   A + I = 2222 → 2x + 2y = 0 → y = −x → v₂ = −11 2本の式が同じ式になるのがポイント（つぶれている＝行が1本ぶん無駄）。 だから解は1本の直線ぶんだけ残る＝固有ベクトルは定数倍の自由度をもつ

05対角化 A = PDP⁻¹ — 3段アニメ

固有ベクトルを列に並べて P を作り、固有値を対角に並べて D を作ります。 これだけで A が3つの操作の合成に分解できます。

P = [ v₁ v₂ ] = 1−111 ,   D = 300−1 ,   P⁻¹ = 12 11−11 A = P D P⁻¹ det P = 1·1 − (−1)·1 = 2 ≠ 0 なので P は可逆。つまり対角化できる

固有基底（eigenbasis）とは

基底とは、平面上のどんな点でも「その2本の組み合わせ」で書ける、独立な2本のベクトルの組のこと。 ふだん使っているのは e₁ = (1,0), e₂ = (0,1) という標準基底で、 (x, y) という書き方はこの2本を何個ぶん使ったかという意味でした。

その2本を固有ベクトルで取り替えたものが固有基底です。今回なら v₁ = (1,1) と v₂ = (−1,1) の組 {v₁, v₂}。 この2本は平行でないので、どんな点も一通りに書けます。

任意の点   v = c₁v₁ + c₂v₂  →  この (c₁, c₂) が固有座標 Av = c₁·3v₁ + c₂·(−1)v₂ A をかけても v₁ 成分と v₂ 成分が混ざらない。ただ 3 倍と −1 倍されるだけ

これが固有基底のうれしさです。標準基底で見ると x と y が互いに流れ込む（x + 2y, 2x + y）ので ごちゃっとして見えますが、固有基底で見ると2本の独立な掛け算に分かれます。

P
固有座標 (c₁, c₂) を受け取って、標準座標 (x, y) を返す（固有ベクトルを列に並べただけ）
P⁻¹
その逆。標準座標を固有座標に翻訳する。だから対角化はここから始まる
D
固有座標のまま、成分ごとに倍率をかける

具体例。(1, 0) = ½v₁ − ½v₂ なので固有座標は (½, −½)。 これに D をかけると (3/2, 1/2)、標準座標に戻すと (3/2)(1,1) + (1/2)(−1,1) = (1, 2)。 たしかに A(1,0) = (1, 2) と一致します。

なお、固有基底はいつでも取れるわけではありません。独立な固有ベクトルが次元ぶん（2次なら2本）そろわない行列は、 固有基底が作れない＝対角化できない。今回は 3 と −1 という別々の固有値から2本そろったので取れました。

「P⁻¹ をかける＝座標を読み替える」って、どういうこと？

いちばん引っかかるところなので、一段ずつ潰します。 45°戻して 1/√2 倍 という言い方の中身も、最後に数字で確かめます。

1
そもそも「座標」は何を数えているのか

(x, y) は「右に x 歩、上に y 歩」という意味でした。この「歩」の正体が e₁ = (1,0) と e₂ = (0,1)。 つまり (3, 3) は e₁ を3歩、e₂ を3歩という記録です。

ここで歩き方を変えます。v₁ = (1,1) 方向を1歩、 v₂ = (−1,1) 方向を1歩と決め直すと、同じ点 (3,3) は

(3, 3) = 3·v₁ + 0·v₂  →  この定規では「(3, 0)」 点は1ミリも動いていない。使う定規（基底）を変えたから数字が変わっただけ
2
P は「固有座標 → 標準座標」の翻訳機

行列 × ベクトルは、実は列の重み付き和という意味しかありません。

P c₁c₂ = c₁·(Pの1列目) + c₂·(Pの2列目) = c₁v₁ + c₂v₂ P の列は v₁ と v₂ を並べただけ。だから「固有座標を入れると標準座標が出てくる」

試すと P(3, 0) = 3·(1,1) + 0·(−1,1) = (3, 3)。1 の逆向きになっています。

3
だから P⁻¹ は逆向き＝標準座標を固有座標に翻訳する
P⁻¹ 33 = 12(3+3, −3+3) = (3, 0)

「P⁻¹ をかける」とは、この点、固有の定規で測ると何歩と何歩？を計算すること。 それが「固有基底で見た座標に読み替える」の中身です。

4
「45°戻して 1/√2 倍」の正体

P の中身をよく見ると、実は回転でした。

  • v₁ = (1,1) と v₂ = (−1,1) はどちらも長さ √2
  • 長さ1にすると (1,1)/√2 = (cos45°, sin45°)、(−1,1)/√2 = (cos135°, sin135°)
  • つまり P = √2 · R(45°)（45°回転を √2 倍したもの）
  • ひっくり返すと P⁻¹ = R(−45°) ÷ √2 ＝ 45°戻して 1/√2 倍

数字で確かめます。(3,3) は45°の向き・長さ 3√2 ≒ 4.24。

操作結果
45°戻す（時計回り）x軸上の長さ4.24 → (4.24, 0)
1/√2 倍(3, 0) ← 3 の計算と一致
1/√2 が出てくる理由は「選んだ定規が長さ1ではなく √2 だから」だけ。 §7 で長さ1に揃えた Q を使うと係数が消えて Q⁻¹ = R(−45°) ちょうどになります。 これが「対称行列だと直交行列で対角化できて気持ちいい」の実体です。
5
読み替えなのに、なぜアニメでは図形が動くのか

理由は、画面はいつでも「標準座標のマス目」で描いているからです。 読み替えの結果 (3,0) という数字が出たら、アニメはその数字を素直に標準のマス目に置きます。 だから見た目には点が (3,3) から (3,0) へ移動します。同じことの2つの見方：

見方絵
(a) 点は固定、定規を斜めに傾ける「読み替え」の素直な姿。首をかしげて見る
(b) 定規は固定、点を動かす行列をかける計算そのままの姿

§5のアニメは (b) を描いていますが、意味しているのは (a)。だから 「斜めだった金・青の軸が、水平・垂直に立つ」という見え方になります。 斜めの軸を立て直した、と読めば同じことです。

6
なぜ P⁻¹ から始めるのか

D は「x軸方向に3倍、y軸方向に −1 倍」という、まっすぐな軸に沿った操作しか知りません。 今回伸ばしたい軸は斜め45°なので、D には直接扱えない。だから順番はこうなります。

板を回してまっすぐ置く（P⁻¹）→ 切る（D）→ 元の向きに戻す（P） 斜めに置かれた板をノコギリで真っ直ぐ切りたいときと同じ。 A = PDP⁻¹ はこの3手順を1本の式にしたもので、右から順に効く（P⁻¹ が先に v にぶつかる）

読み方はこうです。

P⁻¹ をかける — 世界を固有基底で見た座標（＝固有座標）に読み替える。今回は 45°戻して 1/√2 倍。
D をかける — その座標では、ただの軸ごとの伸縮。x′ 軸に 3 倍、y′ 軸に −1 倍（＝折り返し）。斜めの成分はゼロ。
P をかける — 元の座標に戻す。45°回して √2 倍。

07うれしさ② — 対称行列だから直交対角化できる

今回の A は Aᵀ = A（対称）でした。このとき固有ベクトルは必ず直交します。 実際 v₁ · v₂ = 1·(−1) + 1·1 = 0。

そこで v₁, v₂ を長さ1に正規化して並べると、P は回転行列そのものになり、 P⁻¹ を計算する必要さえなくなります（転置でよい）。
