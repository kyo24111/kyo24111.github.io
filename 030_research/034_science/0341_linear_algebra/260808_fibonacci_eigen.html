フィボナッチで見る固有値・固有ベクトル

フィボナッチの漸化式は、行列 A を1回かける操作に書き換えられます。 このとき 点 (λ, 1) だけは、A をかけても向きが変わらず λ 倍に伸びるだけ。 実際に (λ,1) → (λ²,λ) → (λ³,λ²) → … と xy 平面を動かしてみると、 固有ベクトルが「行列が伸縮しかしない方向」であることが目で見えます。

途中で使ったのは λ² = λ + 1 だけ。 これは特性方程式そのもの＝漸化式と同じ形です。だから λ²=λ+1 の解

λ₁ = (1+√5)/2 = 1.6180…（黄金比 φ）  /   λ₂ = (1−√5)/2 = −0.6180…

に対して v₁=(λ₁,1), v₂=(λ₂,1) が固有ベクトルになります。 A をかけると、この2方向の上では 直線に沿ってスライドするだけ： (λ,1) → (λ²,λ) → (λ³,λ²) → …

見どころ. ① λ₁ モード：点はずっと同じ直線の上を、毎回 1.618 倍ずつ外へ。向きは1度も変わらない（＝固有ベクトル）。
② λ₂ モード：同じく直線上だが、倍率が負なので原点をまたいで反対側へ飛び、しかも 0.618 倍に縮む。何度もかけると原点に吸い込まれて消える。
③ フィボナッチ：出発点 (1,0) は固有ベクトルではないので最初はカクカク折れるが、すぐに λ₁ の直線に貼りつく。これが Fn+1/Fn → φ の正体です。

なぜ一般の点も λ₁ の直線に吸い寄せられるのか

出発点を2つの固有ベクトルの足し算に分解しておくと、A をかけるのは 各成分をそれぞれ λ 倍するだけの操作になります。(1,0) = (v₁ − v₂)/√5 なので

|λ₁| = 1.618 > 1 なので第1項は指数的に増え、|λ₂| = 0.618 < 1 なので第2項は指数的に消えます。 残るのは λ₁ⁿ v₁ だけ ⇒ 向きは v₁、倍率は毎回 φ。 ちなみに第2成分を取り出せば Fn = (λ₁ⁿ − λ₂ⁿ)/√5（ビネの公式）です。

λ₁ = 1.618支配的な固有値
|λ|>1 の方向は伸び続ける。長い目で見ると系全体の振る舞い・成長率を決めるのはここ。
λ₂ = −0.618消える固有値
|λ|<1 の方向は縮んで消える。負号は「毎回原点をまたいで反対側に振れる」＝振動として現れる。

固有ベクトル＝行列が「回さない」方向、固有値＝その方向での伸び率。 行列のべき乗 Aⁿ は、この方向たちの上では単なる λⁿ の掛け算に化けます。
