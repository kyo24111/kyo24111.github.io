2×2行列の対角化 ②
A = 3122

1本目（A = [[1,2],[2,1]]）とまったく同じ8節の順番で、 別の行列をもう一度通します。成分は 1〜3 の整数、固有値は 4 と 1。 1本目と違うのは3点で、そこがこのページの見どころです。

03固有値を出す — det(A − λI) = 0

アニメで「だいたい45°と117°」と分かりましたが、これを式で正確に出します。

求めたいのは Av = λv かつ v ≠ 0。移項して (A − λI)v = 0。
つまり行列 A − λI が、ゼロでないベクトルをゼロに潰すということ。
潰す ⟺ 面積が0になる ⟺ det(A − λI) = 0。これが固有方程式。

なぜ (−1, 2) を選ぶか

y = −2x 上なら (1, −2) でも (−1, 2) でも固有ベクトルです。 ここで (−1, 2) を採ると det P = +3 になり、 §5の3段アニメが一度もつぶれずに進みます（(1, −2) だと det P = −3 で、 1段目の途中で一度つぶれてしまう）。答えは同じですが、絵の見やすさが変わります。

固有直線の上にある点は、A をかけてもその直線から出られません。 金色（y = x）の上では4倍に伸び、青（y = −2x）の上では 倍率が 1 なので、まったく動きません。

固有値 1 は「伸びも縮みもしない」。だから直線 y = −2x 上のすべての点は A をかけても不動点です（A(−1,2) = (−1,2)、A(−3,6) = (−3,6)、…）。 平面全体は4倍に引き伸ばされているのに、この1本の線だけが完全に固定されている、という絵になります。

05対角化 A = PDP⁻¹ — 3段アニメ

固有ベクトルを列に並べて P を作り、固有値を対角に並べて D を作ります。 並べる順番は対応さえしていれば自由です（v₁ を1列目にしたら D の左上は λ₁）。

P = [ v₁ v₂ ] = 1−112 ,   D = 4001 ,   P⁻¹ = 13 21−11 A = P D P⁻¹ det P = 1·2 − (−1)·1 = 3 ≠ 0 なので P は可逆。つまり対角化できる。 2×2の逆行列は 1/det · [[d, −b], [−c, a]] で出る

固有基底（eigenbasis）とは

基底とは、平面上のどんな点でも「その2本の組み合わせ」で書ける、独立な2本のベクトルの組のこと。 ふだん使っているのは e₁ = (1,0), e₂ = (0,1) という標準基底で、 (x, y) という書き方はこの2本を何個ぶん使ったかという意味でした。

その2本を固有ベクトルで取り替えたものが固有基底です。今回なら v₁ = (1,1) と v₂ = (−1,2) の組 {v₁, v₂}。 この2本は平行でないので、どんな点も一通りに書けます。

任意の点   v = c₁v₁ + c₂v₂  →  この (c₁, c₂) が固有座標 Av = c₁·4v₁ + c₂·1v₂ A をかけても v₁ 成分と v₂ 成分が混ざらない。 c₁ が4倍になり、c₂ はそのまま置かれるだけ

これが固有基底のうれしさです。標準基底で見ると x と y が互いに流れ込む（3x + y, 2x + 2y）ので ごちゃっとして見えますが、固有基底で見ると「片方を4倍、もう片方は放置」だけになります。

P
固有座標 (c₁, c₂) を受け取って、標準座標 (x, y) を返す（固有ベクトルを列に並べただけ）
P⁻¹
その逆。標準座標を固有座標に翻訳する。だから対角化はここから始まる
D
固有座標のまま、成分ごとに倍率をかける

具体例。(1, 0) の固有座標は P⁻¹(1,0) = ⅓(2, −1) = (2/3, −1/3)。 これに D をかけると (8/3, −1/3)、標準座標に戻すと (8/3)(1,1) + (−1/3)(−1,2) = (3, 2)。 たしかに A(1,0) = (3, 2)（A の1列目）と一致します。

なお、固有基底はいつでも取れるわけではありません。独立な固有ベクトルが次元ぶん（2次なら2本）そろわない行列は、 固有基底が作れない＝対角化できない。今回は 4 と 1 という別々の固有値から2本そろったので取れました。

「P⁻¹ をかける＝座標を読み替える」って、どういうこと？

いちばん引っかかるところなので、一段ずつ潰します。

1
そもそも「座標」は何を数えているのか

(x, y) は「右に x 歩、上に y 歩」という意味でした。この「歩」の正体が e₁ = (1,0) と e₂ = (0,1)。 つまり (2, 2) は e₁ を2歩、e₂ を2歩という記録です。

ここで歩き方を変えます。v₁ = (1,1) 方向を1歩、 v₂ = (−1,2) 方向を1歩と決め直すと、同じ点 (2,2) は

(2, 2) = 2·v₁ + 0·v₂  →  この定規では「(2, 0)」 点は1ミリも動いていない。使う定規（基底）を変えたから数字が変わっただけ
2
P は「固有座標 → 標準座標」の翻訳機

行列 × ベクトルは、実は列の重み付き和という意味しかありません。

P c₁c₂ = c₁·(Pの1列目) + c₂·(Pの2列目) = c₁v₁ + c₂v₂ P の列は v₁ と v₂ を並べただけ。だから「固有座標を入れると標準座標が出てくる」

試すと P(2, 0) = 2·(1,1) + 0·(−1,2) = (2, 2)。1 の逆向きになっています。

3
だから P⁻¹ は逆向き＝標準座標を固有座標に翻訳する
P⁻¹ 22 = 13(2·2 + 1·2,  −1·2 + 1·2) = 13(6, 0) = (2, 0)

「P⁻¹ をかける」とは、この点、固有の定規で測ると何歩と何歩？を計算すること。 それが「固有基底で見た座標に読み替える」の中身です。

4
今回の P⁻¹ は「回転」ではない

1本目では P = √2 · R(45°)、つまり P⁻¹ が「45°戻して 1/√2 倍」というきれいな形でした。 今回はそうなりません。理由は P の2つの列を見れば分かります。

チェック1本目 [[1,2],[2,1]]今回 [[3,1],[2,2]]
列の長さ√2 と √2（同じ）√2 と √5（違う）
列が直交する（内積0）しない（内積1）
P の正体回転 × 拡大マス目を平行四辺形に傾ける

なので今回の読み替えは、向きを回すだけでなく、マス目の形そのものを歪める操作になります。 これが一般の場合で、1本目のように回転で済むのは対称行列という特別な事情があったからです（§7で確認）。 ただし式としては何も変わりません — P を作って逆行列を取るだけ。

5
読み替えなのに、なぜアニメでは図形が動くのか

理由は、画面はいつでも「標準座標のマス目」で描いているからです。 読み替えの結果 (2,0) という数字が出たら、アニメはその数字を素直に標準のマス目に置きます。 だから見た目には点が (2,2) から (2,0) へ移動します。同じことの2つの見方：

見方絵
(a) 点は固定、定規を斜めに傾ける「読み替え」の素直な姿。首をかしげて見る
(b) 定規は固定、点を動かす行列をかける計算そのままの姿

下のアニメは (b) を描いていますが、意味しているのは (a)。だから 「斜めだった金・青の軸が、水平・垂直に立つ」という見え方になります。

6
なぜ P⁻¹ から始めるのか

D は「x軸方向に4倍、y軸方向に1倍」という、まっすぐな軸に沿った操作しか知りません。 今回伸ばしたい軸は斜め45°なので、D には直接扱えない。だから順番はこうなります。

板を回してまっすぐ置く（P⁻¹）→ 切る（D）→ 元の向きに戻す（P） 斜めに置かれた板をノコギリで真っ直ぐ切りたいときと同じ。 A = PDP⁻¹ はこの3手順を1本の式にしたもので、右から順に効く（P⁻¹ が先に v にぶつかる）

これを踏まえて、3段の読み方はこうです。

P⁻¹ をかける — 世界を固有基底で見た座標（＝固有座標）に読み替える。斜めの2軸が水平・垂直に立つ。

07対称じゃないと、何が違うのか

1本目の [[1,2],[2,1]] は Aᵀ = A（対称）でした。 今回は Aᵀ = [[3,2],[1,2]] ≠ A。この差で3つのことが崩れます。

固有ベクトルが直交しない。 v₁ · v₂ = 1·(−1) + 1·2 = 1 ≠ 0。1本目は 0 でした。
P が回転にならない。だから P⁻¹ = Pᵀ という近道が使えず、ちゃんと逆行列を計算する必要がある。
楕円の主軸と固有方向がズレる。単位円を A で写した楕円の長軸は 41.4° の向きですが、固有方向は 45°。

3つめが一番目で見て分かります。下のアニメで 「一番よく伸びる向き」と「向きが変わらない向き」が別物だと確認できます。
