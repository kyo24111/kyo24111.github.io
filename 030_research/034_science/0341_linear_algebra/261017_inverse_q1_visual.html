01A は平面をどう動かすか

行列は「平面全体をぐにゃっと動かす変換」。どう動かすかは、2本の基底ベクトルの行き先だけで決まる。

  • e₁ = (1, 0) の行き先 ＝ A の1列目 (2, 3)
  • e₂ = (0, 1) の行き先 ＝ A の2列目 (1, 2)

方眼紙のマス目全体が、この2本に引っ張られて斜めの平行四辺形のマス目になる。下の黒い点 p = (1, 1) は e₁ + e₂ なので、行き先も (2, 3) + (1, 2) = (3, 5)。

見るポイント：マス目は斜めに歪むが、まっすぐな線はまっすぐのまま、原点は動かない、マス目の間隔は均等。これが「線形」変換の見た目。

02A⁻¹ は、その動きを巻き戻す

A⁻¹ は「A で動かした平面を、元の方眼紙に戻す変換」。A をかけてから A⁻¹ をかけると、何もしなかったのと同じ（＝単位行列 E）。

A⁻¹ A = E

(3, 5) に A⁻¹ をかけると (2·3 − 1·5, −3·3 + 2·5) = (1, 1)。ちゃんと p に戻る。

逆に、何も無い状態から A⁻¹ を先にかけてもいい（A A⁻¹ = E）。2×2 の正方行列では、左から掛けても右から掛けても同じ A⁻¹ で戻る。

03A⁻¹ の列は「A が e₁, e₂ に運んでくる元の点」

A の列が「e₁, e₂ の行き先」だったのと同じで、A⁻¹ の列は「A⁻¹ が e₁, e₂ を運ぶ先」。言い換えると、A をかけたらちょうど e₁, e₂ に着地する出発点。

A⁻¹ の列A をかけると意味
u₁ = (2, −3)(2·2 + 1·(−3), 3·2 + 2·(−3)) = (1, 0)e₁ に着地する出発点
u₂ = (−1, 2)(2·(−1) + 1·2, 3·(−1) + 2·2) = (0, 1)e₂ に着地する出発点

下で A をかけると、斜めに散らばっていた u₁, u₂ が、ぴったり e₁, e₂ に吸い込まれる。

ここが核心：逆行列を求める ＝「A で e₁ に飛ぶ点はどこ？ e₂ に飛ぶ点はどこ？」という2本の連立方程式を解くこと。その答えを縦に並べたものが A⁻¹。掃き出し法の [A | E] → [E | A⁻¹] は、この2本を同時に解いている。

04det = 1 は「面積が変わらない」

det は「変換で面積が何倍になるか」。マス1個（面積 1 の正方形）は、A で平行四辺形になる。その面積は

det A = 2·2 − 1·3 = 1

形は大きく歪むのに、面積はぴったり 1 のまま。下のアニメの右上に、いまの面積（＝det）を出している。

途中で面積がいったん 1.5 まで膨らむのは、アニメが E から A へまっすぐ成分を動かしているせい（途中の行列は A ではない）。着地した A の時点では 1 に戻る。

A⁻¹ は A の巻き戻しなので、面積の倍率も逆数 1/det。det = 1 なら A⁻¹ の det も 1。だから公式の「1/det で割る」が要らず、入れ替えて符号を反転するだけで済む。Q1〜Q3 がわざと det = 1 になっているのはこのため。

05「入れ替えて符号反転」は、直交する矢印を作っている

A⁻¹ A = E を成分で書くと、「A⁻¹ の行 × A の列」が

  • 同じ番号どうし（1行目×1列目、2行目×2列目）→ 1
  • 違う番号どうし（1行目×2列目、2行目×1列目）→ 0

内積が 0 ＝ 2本の矢印が直交している。つまり A⁻¹ の1行目は「A の2列目に直交する矢印」、2行目は「A の1列目に直交する矢印」でなければならない。

矢印 (x, y) を 90° 回すと (y, −x)。成分を入れ替えて片方の符号を反転――これが公式の形の正体。

A⁻¹ の行相手の列と（直交 → 0）自分の列と（→ det = 1）
1行目 (2, −1)2列目 (1, 2)：2·1 + (−1)·2 = 01列目 (2, 3)：2·2 + (−1)·3 = 1
2行目 (−3, 2)1列目 (2, 3)：(−3)·2 + 2·3 = 02列目 (1, 2)：(−3)·1 + 2·2 = 1

「自分の列」との内積 ad − bc は、2本の列が作る平行四辺形の面積＝det。だから一般には A⁻¹A = det × E になり、最後に det で割る。det = 1 ならそのまま。

注意：「det = 1 なら符号反転だけ」に見えるのは Q1 の偶然。公式は「a と d を入れ替える＋b, c の符号を反転」。Q1 は a = d = 2 なので、入れ替えても見た目が変わらないだけ。Q2 の [[3, 5], [1, 2]] では入れ替えが効いて [[2, −5], [−1, 3]] になる（符号反転だけの [[3, −5], [−1, 2]] だと A⁻¹A の (1,1) が 3·3 − 5·1 = 4 になり E にならない）。

06連立方程式として読む

A x = b は連立方程式そのもの。

2x + y = α
3x + 2y = β

「A で b に飛んでくる出発点 x はどこ？」という問い。両辺に A⁻¹ をかければ一発で x = A⁻¹ b。

  1. b = (3, 5) なら x = (2·3 − 1·5, −3·3 + 2·5) = (1, 1)
  2. b = (1, 0) なら x = A⁻¹ の1列目 = (2, −3)（§03 の u₁）
  3. b = (0, 1) なら x = A⁻¹ の2列目 = (−1, 2)（§03 の u₂）

検算：2·1 + 1 = 3 ✓、3·1 + 2·1 = 5 ✓。

逆行列が1つ手元にあれば、右辺 b が何に変わっても「掛けるだけ」で解ける。これが逆行列を持っておく嬉しさ。

  • 面積 0：マス目が1本の線に潰れる。戻すには面積を 1/0 倍しないといけない → 不可能。
  • 重なる：白丸 (2, 0) と黒丸 (0, 1) が、どちらも (4, 2) に落ちる。(4, 2) を見ても元がどっちか分からない。
  • 届かない：線の外の点（例：(1, 0)）には、どの出発点からも行けない。

Q1 の A は面積 1 のまま歪むだけなので、どの点も「1対1」で対応が残る。だから巻き戻せる。det ≠ 0 かどうかが、巻き戻せるかどうかの分かれ目。
