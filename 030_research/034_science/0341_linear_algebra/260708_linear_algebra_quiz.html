次元操作・行と列数

Last updated: 2026-07-08

列数＝入力の次元、行数＝出力の次元。積は内側一致で定義、外側がサイズ。

例

3×2 行列は何次元空間から何次元空間への変換か。（サンプル・削除可）

解答・解説

列2＝入力、行3＝出力 → R² → R³。

固有値・固有ベクトル

Last updated: 2026-07-08

① det(A−λE)=0 で λ → ② (A−λE)v=0 の核で v。傾かない軸＝固有ベクトル。三角・対角は対角成分がそのまま固有値。

Q1

次の行列の固有値を求めよ。

解答・解説

λ = 3, 5

まず形を見る。左下が 0 ＝ 上三角行列。三角行列は対角線の数字がそのまま固有値になるので、det(A−λI)=0 を解くまでもなく対角の 3 と 5 が答え。

なぜそうなるか。三角行列の det は対角成分の積。A−λI も上三角のままなので det(A−λI) = (3−λ)(5−λ)。これが 0 になる λ ＝ 対角成分そのもの。

定義どおり計算して検算。

→ det = (3−λ)(5−λ) − 19·0 = (3−λ)(5−λ) = 0 → λ = 3, 5。

手触り：右上の 19 は固有値には一切効かない（左下が 0 で掛け算に絡まないから）。効くのは対角の 3・5 だけ。ただし 19 は固有ベクトルには効くので、v を求めるときは別途 (A−λI)v=0 を解く。
