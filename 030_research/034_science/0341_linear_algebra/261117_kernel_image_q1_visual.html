Kernel と Image を目で見る — 演習06 Q1

Linear Algebra の演習「06 Rank」Q1 の詳細解説。rank ＝ 1 という答えの裏で、平面のどこが消えて（Kernel）、どこに集まるのか（Image）をアニメで追う。章本文は 像（Image）と核（Kernel）。
Last updated: 2026-11-17

Q1. rank を求めよ。M =
12
24

答え. 2行目 ＝ 2 ×（1行目）→ 独立な行は1本 → rank ＝ 1。
このページで分かること. Kernel ＝ 直線 x＋2y＝0（(−2, 1) の方向）、Image ＝ 直線 y＝2x（(1, 2) の方向）、1 ＋ 1 ＝ 2。

01M は平面をどう動かすか — 平面が1本の直線につぶれる

行列の動きは、基底ベクトルの行き先＝列で決まる。

  • e₁ = (1, 0) の行き先 ＝ 1列目 (1, 2)
  • e₂ = (0, 1) の行き先 ＝ 2列目 (2, 4) ＝ 2 ×(1, 2)

2本の行き先が同じ向き（平行）になってしまう。だから方眼紙のマス目は平行四辺形にすらなれず、1本の直線の上にぺしゃんこになる。

見るポイント：灰色のマス（面積 1）が線分になり、面積 ＝ det ＝ 1·4 − 2·2 ＝ 0。平面（2次元）だったものが直線（1次元）になった ＝ rank ＝ 1。「1次元分つぶれた」と言える。

02Image（像）— 行き先は全部、直線 y＝2x の上

Image は「M をかけて出てくるもの全部」。どの点 (x, y) を入れても、

M (x, y) ＝ (x＋2y, 2x＋4y) ＝ (x＋2y) · (1, 2)

つまり出てくるのはいつも (1, 2) の何倍かだけ。下の成分は必ず上の成分の2倍 → Image ＝ 直線 y＝2x（1次元）。

下のアニメでは、平面上の点を x＋2y の値ごとに色分けしている。M をかけると、点が直線 y＝2x に集まる。

列で読むと：Image ＝ 列ベクトル (1, 2) と (2, 4) の Span。2本が平行なので、張るのは直線1本だけ。dim Image ＝ 独立な列の本数 ＝ rank ＝ 1。

よく見ると、同じ色の点が同じ場所に重なっている。違う点が同じ行き先に重なる ＝ 何かが消えている。それが次の Kernel。

03Kernel（核）— 原点に消える直線 x＋2y＝0

Kernel は「M をかけると 0 になる入力全部」。M(x, y) ＝ (x＋2y)·(1, 2) なので、x＋2y ＝ 0 なら 0 になる。

連立方程式で解く：
x ＋ 2y ＝ 0、 2x ＋ 4y ＝ 0（2本目は1本目の2倍 → 実質1本）
→ y ＝ −x/2 → x ＝ −2 と置くと (−2, 1)。
確認：M(−2, 1) ＝ (−2＋2, −4＋4) ＝ (0, 0) ✓
→ Kernel ＝ (−2, 1) の定数倍全体 ＝ 直線 x＋2y＝0（1次元）

赤い直線が Kernel。M をかけると、赤い直線の上の点は全部原点に吸い込まれる。黒い点 (1, 0) は Kernel の外なので (1, 2) に残る。

直線ごと消える理由：M(−2, 1) ＝ 0 なら、何倍しても M(c·(−2, 1)) ＝ c·0 ＝ 0。だから Kernel は「矢印1本」ではなく、その矢印が乗っている直線全体。

04平面は「Kernel に平行な直線」の束 — 1本が1点につぶれる

ここが一番深いところ。Kernel 以外の点はどうなるか？

平面を、Kernel に平行な直線 x＋2y ＝ c（c ＝ …, −2, −1, 0, 1, 2, …）で切り分けてみる。c ＝ 0 の線が Kernel そのもの。

x＋2y ＝ c の上の点 → M をかけると → c · (1, 2)（1点）

1本の直線が丸ごと Image 上の1点につぶれる。Kernel の方向（直線に沿った向き）の情報が消えて、c（どの直線にいたか）だけが残る。

入力の直線例の点行き先
x＋2y ＝ 0（Kernel）(0, 0)、(−2, 1)、(2, −1)(0, 0)
x＋2y ＝ 1(1, 0)、(−1, 1)、(3, −1)(1, 2)
x＋2y ＝ 2(2, 0)、(0, 1)、(4, −1)(2, 4)
x＋2y ＝ −1(−1, 0)、(1, −1)(−1, −2)
まとめると：平面（2次元）＝「どの直線か（c, 1次元）」×「直線の中のどこか（Kernel 方向, 1次元）」。M は後ろの1次元（Kernel）を捨てて、前の1次元（c）を Image に送る。
→ 2 ＝ 1（Kernel, 潰れる）＋ 1（Image, 出てくる）。これが次元公式の中身。

05次元公式で確かめる

量値どこから
入力の次元 n2列が2本（2×2 行列）
dim Image（rank）1独立な列（行）が1本
dim Kernel（nullity）1式が実質1本 → 自由な変数が 2−1＝1 個
確認1 ＋ 1 ＝ 2rank ＋ nullity ＝ n

授業（261112, 26:18〜）の言い方：「2次元を送るのに、Kernel 1次元分が潰れたことで、Image が 2−1＝1次元になる」。潰れた分だけ、出てくるものが減る。

06Kernel と Image が直交しているのは「たまたま」？

Kernel (−2, 1) と Image (1, 2) の内積は −2＋2 ＝ 0 で、直交している。授業（26:04）での質問。

理由：
① Mv ＝ 0 は「v と各行の内積が 0」という意味 → Kernel はいつでも行ベクトルに直交する。
② Image は列ベクトルの Span。
③ M は対称行列（行 ＝ 列）なので、行に直交 ＝ 列に直交 ＝ Image に直交。

対称でない行列と比べると違いが見える。M' ＝ [[1, 2], [0, 0]] は Kernel は同じ x＋2y＝0 だが、列が (1, 0) と (2, 0) なので Image は x 軸 → 直交しない。

07連立方程式 Mv ＝ b で読む

右辺 bb は Image 上？解
(3, 6)○（y＝2x の上）無数：直線 x＋2y＝3 の全部。(3, 0)＋t(−2, 1)
(0, 0)○無数：Kernel そのもの。t(−2, 1)
(1, 0)×（y＝2x の外）解なし：x＋2y＝1 と 2x＋4y＝0 が矛盾

Image が「解があるか」、Kernel が「解がいくつあるか」を決める。Image が平面全体でない（どこにも届くわけではない）ので解なしの b があり、Kernel が {0} でない（ずらせる）ので解があっても1つに決まらない。

08まとめ — 同じことの言い換え

見方M ＝ [[1,2],[2,4]]
行（列）の独立性2行目 ＝ 2×1行目 → 独立なのは1本
rank1（フルランクでない）
det1·4 − 2·2 ＝ 0（面積が 0 につぶれる）
Image直線 y＝2x（1次元）
Kernel直線 x＋2y＝0（1次元）、(−2, 1) の方向
逆行列なし（違う点が同じ場所に重なるので戻せない）

正方行列では「rank 落ち ⇔ det＝0 ⇔ Kernel が {0} でない ⇔ Image が全体でない ⇔ 逆行列なし」が全部同じこと。逆行列が作れる側の例は 演習07 Q1 の詳細解説。
