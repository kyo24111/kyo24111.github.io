# Linear Algebra — 運用ルール

このフォルダはKyoの線形代数の勉強・復習を蓄積する場所。

## 目的

- 学んだことを忘れずに積み上げる
- いつでも復習できるリファレンスにする

## 編集ルール

1. **ページ構成はprompt駆動**
   - Kyoが入力したpromptの内容・順序に沿ってのみpageを構成する
   - 勝手にトピックを補完・追加しない
2. **書きすぎない**
   - まとまりが崩れないよう、promptで指定された範囲だけ書く
   - 余計な背景説明・章立て・参考文献の自動追加はしない
3. **既存内容との接続**
   - 新しい項目を追加するときは、既存セクションとの関連を最小限示す
   - 重複が起きそうな場合は既存セクションを更新する形にする
