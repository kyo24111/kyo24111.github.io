なぜ「斜め軸で 120°」になるのか

合成 R が 3 本の矢印に何をするか、列を読むだけで分かります。

x軸の矢印 → y の位置 → z の位置 → x に戻る。 つまり x → y → z → x の巡回置換。3 本を 1 つずつ送る＝ちょうど 1/3 周 = 120° の回転です。

その回転が「どの軸のまわりか」を決めるのが固有ベクトル。回っても動かない方向を探すので、 R·v = v、すなわち (R − I)·v = 0 を解きます — これは 固有値 λ = 1 の固有ベクトルそのもの。

この例では v = (1, 1, 1)。実際に代入すると、行列の各行が 1+1+1 を拾って R·(1,1,1) = (1,1,1)。x・y・z から等距離にある対角線だから、 3 軸を対称に入れ替える軸になる、というわけです。

核心（線型写像 × 固有値の視点）

3 次元では、回転をいくつ合成しても結果はまた 1 つの回転になる（オイラーの回転定理）。 その回転の軸＝固有値 1 の固有ベクトル、回転角＝残り 2 つの複素固有値 e±iθ の θ。ここでは軸 (1,1,1)、 θ = 120° でした。

「縦＋横を足したら斜めに回っていた」という現象は、 合成行列の固有ベクトルが座標軸からズレた方向を向いていた、ということの見た目上の姿です。 上の ① と ② がまったく同じ最終姿勢に着地するのが、その証拠。

一段上へ：直交行列・SO(3)・O(3)

回転行列は直交行列。列ベクトルが互いに直交する長さ1の基底で、RᵀR = I （＝ R⁻¹ = Rᵀ）。これは「長さと角度を保つ」写像であることと同値です。 長さを保つ 3×3 の写像を全部集めたのが O(3)。

そのうち det R = +1 のもの＝裏返しを含まない純粋な回転が SO(3) （S = Special = 行列式1）。det R = −1 側が鏡映（裏返し）や回転＋裏返し。 あなたの整理どおり、裏返しも入れると O(3) です。

固有ベクトル = 回っても向きを変えない方向 = 軸。この対応もあなたの言うとおり。 だから自然に湧く疑問——「SO(3) の行列を一つ取ってきたら、固有ベクトル（＝軸）は必ずあるのか?」

答え：必ずある（オイラーの回転定理）

SO(3) の任意の R は、固有値 λ = 1 の実固有ベクトルを必ず持つ。理由は3行:

・直交行列の固有値は絶対値1（長さを保つから |λ| = 1）。
・特性方程式は 3次＝奇数次なので、実根が少なくとも1つある。実で |λ|=1 なら λ = ±1。
・固有値の積 = det R = +1。残り2つは複素共役ペア e±iθ（積は1）だから、 実固有値は +1 で確定。

その λ=1 の固有ベクトルが回転軸。残りの e±iθ の θ が回転角（この教材では 120°）。「縦＋横を合成したら斜めに回っていた」の正体は、 この 固有値1の固有ベクトルが座標軸からズレた向きだった、というだけのこと。

対比で腹落ちする点：SO(2)（平面の回転）は固有値が e±iθ だけで実固有ベクトルを持たない＝2次元の回転に軸はない。 「軸が生まれる」のは奇数次元だからこそ。O(3) の det=−1 側なら λ=−1（裏返す方向）が現れる。
