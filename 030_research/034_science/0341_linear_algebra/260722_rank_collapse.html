単位行列が潰れるとき — rank 3 / 2 / 1 を目で見る

3×3 の単位行列 I は、空間の3つの方向（x・y・z）をそのまま保ちます。 ここから列ベクトルを少しずつ「依存」させていくと、単位立方体は 平面（rank 2）へ、さらに 直線（rank 1）へと潰れていきます。 rank とは「像が何次元に残るか」＝ 生き残る独立な方向の数のことです。

上のタブで「潰れ方」を切り替え。det が 0 に近づく＝立方体が薄くなる＝rank が落ちる、が同じ現象の3つの言い換えだと分かります。ドラッグで視点も回せます。

3つの事例

それぞれ、単位行列の列（＝空間の基底 e₁,e₂,e₃ の行き先）をどう仕込んだかです。

RANK 3そのまま — 全方向が生き残る

3本の列ベクトルが互いに独立。像は3次元空間まるごと。

M =

1.0−0.20.1
0.31.0−0.3
0.20.31.0
→ det ≠ 0、逆行列あり。立方体は傾いた平行六面体になるが、体積は残る。

RANK 21つ落ちる — 平面に潰れる

列3 = 列1 + 列2。3本目が最初の2本の張る平面に乗ってしまう（従属）。

M =

1.00.21.2
0.21.01.2
0.3−0.20.1
→ det = 0。立方体は厚みを失い 平面（平行四辺形）に。奥行き方向の情報は消える。

RANK 12つ落ちる — 直線に潰れる

列1・列2・列3 がすべて同じ向き v の定数倍。独立な方向は1つだけ。

M =

1.00.81.2
0.60.480.72
0.40.320.48
→ det = 0。立方体は 1本の線分に潰れる。空間全体が1本の直線へ写る。

21枚の平面ぺったんこ（面積のみ）= 0なし
11本の直線線分（長さのみ）= 0なし

rank ＝ 潰れた後に残る次元の数。列が1本従属になるごとに次元が1つ減り、det は 0 に貼りつく。 det = 0 ⇔ 潰れている ⇔ フルランクでない ⇔ 逆行列なし、はすべて同じことです。
