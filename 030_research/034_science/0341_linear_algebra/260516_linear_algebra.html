次元のセンスで読む

前節で見た「対角行列 = 各軸を独立にスケール」を、相手が行列のときに当てはめると：

D · M：　M を「出力側の3軸（行）」で受け取って、各軸を独立にスケール
M · D：　D を先に効かせるので、M の「入力側の3軸（列）」が各々スケールされてから M が変換

M を「ℝ³ → ℝ³ の変換」と見ると：

  • DM = M の出力をさらに伸縮 → 後処理のスケール
  • MD = 入力を先に伸縮してから M に渡す → 前処理のスケール
一行まとめ：左から対角は「出力軸の重み付け（行スケール）」、右から対角は「入力軸の重み付け（列スケール）」。
→ ニューラルネットの「層ごとの重み・正規化」やデータ前処理の特徴量スケーリングは、まさにこの右掛けに対応する。

なぜ嬉しいか（計算が極端に簡単）

対角行列はあらゆる演算が成分ごとに独立になるので、計算コストが激安。

  • ベクトルとの積：各成分を対角成分で倍するだけ
  • べき乗：Dk = diag(d₁k, …, dₙk) — 各対角成分を k 乗するだけ
  • 行列式：det(D) = d₁ · d₂ · … · dₙ（対角成分の積）
  • 逆行列：D-1 = diag(1/d₁, …, 1/dₙ)（すべての d ≠ 0 が条件）
  • 固有値：対角成分そのものが固有値

これが対角化（Diagonalization）のモチベーション — 普通の行列を、適切な基底に乗り換えることで 対角行列と同等な形に変えて、計算を激減させる。

シフト行列（Shift Matrix）理解

入力 (x, y, z) → 出力 (y, z, 0)。成分が1つずつ上にスライドし、一番下に 0 が押し込まれる。1ステップで情報が "前にずれる" のでシフト行列。
対角のすぐ上に並ぶ 1 たちが「次の成分を引っ張り上げる」役を担っている — まさにジョルダンブロックの 1 と同じ構造。

実世界での使い道：時系列データと相性が良い理解

ぱっと見「0 が大半でいかにも美しくない行列」だが、シフト行列は時系列データを扱う場面で頻繁に現れる：

  • M の各行を 時刻 t=0, t=1, t=2 のスナップショット（売上・株価・センサー値など）と読むと、NM は「全員の時刻を1つ進める」操作と同義
  • 計量経済の ラグ作用素（lag operator） や、信号処理の遅延線、AR モデルの状態遷移などはこの構造の一般化
  • 一番古い行（情報）が消える＝"観測窓" を進めると過去が落ちるという現実的な制約を、行列1つで表現できる
コラム：ジョルダン細胞（Jordan Cell）
対角に同じ固有値 λ が並び、そのすぐ上（superdiagonal）に 1 が並ぶ正方行列を ジョルダン細胞（Jordan cell, または Jordan block）と呼ぶ。形は λI + N — つまり 単位行列のスケール（λI）＋ シフト行列（N） の足し算。
いま見ているのは λ = 0 のケース（純粋なシフト＝ニルポテント）。一般の λ ≠ 0 の細胞は、対角化できない行列を分解する最小単位として登場する。深入りは Chapter 6（ジョルダン標準形）で扱う — 今は「シフトは Jordan の 1 ピース」とだけ覚えておけば OK。

Nk = O　（ゼロ行列）
を満たすとき、N を ニルポテント行列（nilpotent matrix）と呼ぶ。
本質：「k 回掛け続けると必ずゼロ行列に潰れる」という一点に尽きる。情報を捨て続ける変換の極限形。
なぜ「正方行列」限定なのか：
Nk = N · N · … · N という自分自身との繰り返し積を考えるには、左の列数と右の行数が一致しなければならない（前 Chapter「列数 = 行数」のルール）。つまり N が n × n でなければ N² すら定義できない。
→ ニルポテント・ジョルダンブロック・対角化など、「繰り返し適用」を扱う議論はすべて正方行列の世界の話。

可換性（Commutativity）

定義 — 可換とは「AB = BA」

2つの正方行列 A, B が AB = BA を満たすとき、A と B は 可換（commutative）であるという。逆に AB ≠ BA なら 非可換（non-commutative）。

A · B = B · A　⇔　A と B は可換

サイズの前提：AB と BA の両方が定義できる必要があるので、A・B はともに同じサイズの 正方行列（n × n）。長方形行列では片方の積しか定義できないことが多く、可換性の議論自体が成り立たない。

数の世界との違い：普通の数なら 3 × 5 = 5 × 3 で当たり前に可換。
行列は「数の延長」ではなく「操作（変換）の代数」なので、順序が結果を変えるのが基本。可換になる方が 特殊なケースと捉えるのが正しい姿勢。

→ 詳しい計算例と非可換の体感は Chapter 3（3-2 非可換性）を参照。

可換になる組み合わせ — 構造で覚える

「どんな A, B が可換になるか」を場当たり的に覚えるのではなく、なぜ可換になるかの理由ごとに整理する。

組み合わせ 理由
A と I（単位行列）I は「何もしない」変換 — 順序に意味がない
A と O（ゼロ行列）どちらの順でも結果はすべて 0
A と A-1（逆行列）どちらの順でも打ち消し合って I になる
A と Ak（自分のべき）同じ行列同士なので入れ替える相手がいない
対角行列同士 D, D'各軸を独立にスケールするだけ — 軸が混ざらない

同じ固有ベクトルを共有する2つの行列同時対角化可能 — 共通の基底でどちらも対角になる（最深の理由）
統一的な見方：可換になるのは 「両者の作用が、共通の軸（基底）の上で独立に動く」 ようなとき。軸が混ざらなければ順序は問題にならない。逆に、回転と鏡映のように軸を絡める変換同士は一般に非可換。

幾何的な意味 — 「軸が共有されているか」

可換性は計算ルール上の話というより、2つの変換が互いの "座標軸" を尊重し合っているかという幾何的な問い。

  • 可換のとき：A も B も 同じ軸の上でそれぞれの仕事をする。例：x軸を3倍 × y軸を2倍 は、順序を変えても同じ点に着地
  • 非可換のとき：A が動かす軸と B が動かす軸が 互いに混ぜ合わさる。例：90°回転してから鏡映 ≠ 鏡映してから90°回転
アナロジー：「靴下を履く」と「ズボンを履く」は順序を入れ替えても OK（独立な作業）→ 可換。
「靴下を履く」と「靴を履く」は逆順だと成り立たない（依存する作業）→ 非可換。

なぜ可換性を気にするのか — 同時対角化への伏線

可換性は単なる "計算上の便利さ" にとどまらない。2つの行列が可換 ⇔ 同じ基底で同時に対角化できるという深い同値が知られている（Aが対角化可能で重複固有値がない場合などの条件下）。

A, B が可換 ⇔ 共通の固有ベクトル基底 を取れば、両方を同時に対角に書ける
（厳密には A・B 共に対角化可能などの条件が必要）

これは「複数の変換を同時に "見やすい座標" で扱える」ことを意味し、物理（量子力学の同時観測可能量）・統計（共分散構造の分解）・信号処理（同時フィルタ設計）などで本質的に利く。

量子力学とのつながり（コラム）：2つの観測量（演算子）A, B が可換 ⇔ 同時に正確に測れる。位置と運動量は非可換（[x, p] ≠ 0）なので不確定性原理が生じる、というあの話の根っこ。

Span（張られる空間）

定義理解

いくつかのベクトルを スカラー倍して足し合わせる ことで到達できる、すべての点の集合のことを Span（スパン・張られる空間）と呼ぶ。

Span(v₁, v₂, …, vₖ) = { c₁v₁ + c₂v₂ + … + cₖvₖ | c₁, …, cₖ ∈ ℝ }

前のChapter「2次元 → 3次元」で見た例では、列ベクトル (1, 2, 4) と (2, 3, -1) の Span が、ℝ³ の中の特定の2次元平面。
この平面が行列の 像（Image / Range）、その次元（=平面の本数）が 階数（Rank）= 2。

Span と一次独立理解

Span の「広がり（次元）」は、含まれるベクトルが互いに本当に違う方向を向いているか で決まる。これを 一次独立（Linear Independence） という。

一次独立：どのベクトルも、他のベクトルの線形結合では作れない関係。
一次従属：どれか1本が、他の線形結合で作れてしまう関係。「同じ方向の二度書き」が混ざっている状態。

k本のベクトルが一次独立 ⇔ Span の次元 = k
一次従属が混ざる ⇔ Span は "潰れて" 小さくなる

例①：独立な2本　v₁ = (1, 0)、v₂ = (0, 1)
どちらも独立 → Span(v₁, v₂) = ℝ²（平面全体）

例②：従属な2本　v₁ = (1, 0)、v₂ = (2, 0)
v₂ = 2·v₁ なので同じ方向 → Span(v₁, v₂) = x軸上の直線（1次元）
本数は2本だが、実質1方向しか張れない。

直感：マスターキーが何本あっても、それぞれが同じドアを開ける鍵だったら、開けられる部屋は1つしか増えない。
一次独立 = 「新しいドア」を開く鍵が増えること。

基底と一次独立理解

空間を表現するのに「ちょうど良い本数」の 一次独立なベクトルの組 を選ぶと、それを 基底（Basis） という。

基底 = 「一次独立」 ∧ 「空間全体を Span できる」
= 最小の本数で空間を張り切れるベクトルの組

— 集合の交わりとして見る —

A：一次独立
どれも他の組み合わせで作れない
B：全体を Span
空間内のどの点にも届く
A ∩ B = 基底
過不足がない
読み方：
  • A だけ（独立だが Span しない）：本数が足りず、空間の一部しか届かない（例：ℝ³ で2本だけ独立 → 平面しか張れない）
  • B だけ（Span するが独立でない）：本数が多すぎて重複（一次従属）が混ざる（例：ℝ² で3本 → 必ず1本は他で作れる）
  • A ∩ B：独立性も全体被覆も両立している、唯一の "ちょうど良い" 状態 = 基底。これが基底の美しさ — 過不足がない。

特徴：

  • ℝⁿ の基底は必ず n本。1本多くても少なくてもダメ。
  • 空間内のどの点も、基底ベクトルの 線形結合として一意に分解 できる。
  • 基底は1組ではなく、いくつでも選び方がある（一次独立で n本なら何でも良い）。

標準基底（Standard Basis）：ℝ² では e₁ = (1, 0), e₂ = (0, 1)。最も「軸らしい」基底。
ℝ³ では e₁ = (1, 0, 0), e₂ = (0, 1, 0), e₃ = (0, 0, 1)。

直感：前Chapterで使った「マスターキー」表現で言うと、基底 = 空間を全部開けられる最小本数のマスターキーの組。
・1本足りない → 開けられない部屋（次元）が残る

4次元以上の Span理解

3次元までの Span（直線・平面・立体）は脳内で可視化できるが、数学的には 4次元・100次元・1万次元の Span も同じように存在する。

4次元以上は人間の視覚では捉えられないが、計算ルールは変わらない。実世界の応用ではむしろ高次元の方が普通。

直感：店舗データ × 4変数
例えば店舗ごとに次の4つの独立な変数を持つとする：
・売上 (sales)　・顧客数 (visitors)　・在庫 (inventory)　・立地スコア (location)
1店舗 = ℝ⁴ の中の1点。
全店舗のデータ集合 = ℝ⁴ の中に分布する点群 → Span を考えれば何次元の "本質的な広がり" を持つか が分かる。

「実は売上 ≒ 顧客数×単価」なら、その2変数は一次従属に近く、4変数のうち本質的には3次元の Span しか張れていない可能性がある。
→ こうした考え方が 主成分分析（PCA） や 階数（Rank） の概念に直結する。

コラム：主成分分析（PCA）とは、Spanとの関わり
PCA（Principal Component Analysis） は、高次元データを「本質的な広がりが大きい方向」から順に新しい基底として並べ替える手法。
  • 元の変数（売上・顧客数・在庫・立地）は独立に見えても実際は相関があり、データ全体は ℝ⁴ の中の"細長い雲" のような部分空間 に集まる。
  • PCA はその雲を見て、最も広がっている方向 = 第1主成分、それに直交する次に広い方向 = 第2主成分、… と新しい基底を取る。
  • 上位2〜3本でデータの分散の大半を説明できるなら、本来 ℝ⁴ にあったデータを ℝ² や ℝ³ に圧縮 できる（= 次元削減）。
Span との関係：
  • PCA が選ぶ主成分の組は、データが実質的に張る部分空間（Span）の正規直交基底。
  • 「ℝ⁴ の中で実は3次元しか張られていない」を見抜く道具。データの本質的な階数（Rank） を推定するアプローチでもある。

Rank（階数）

定義

行列を列ベクトルに分解したとき、一次独立なベクトルが実質何本入っているか を表す数。それが Rank（階数）。

rank(A) = 列ベクトルの一次独立な本数 = Span(列ベクトル) の次元

つまり rank = 出力空間の本当の次元。行列のサイズが大きくても、列同士が比例していたりすれば rank は小さくなる。

列ベクトル視点で数えても、行ベクトル視点で数えても結果は同じ（列rank = 行rank の定理）。

フルランク（Full Rank）

rank が取りうる最大値に達している状態を フルランク と呼ぶ。

m×n 行列の最大 rank = min(m, n)
rank(A) = min(m, n) ⇔ フルランク

パターン別の意味：

  • m ≤ n（横長 or 正方）：rank = m → 行が全部独立 = フル行ランク
  • m ≥ n（縦長 or 正方）：rank = n → 列が全部独立 = フル列ランク
  • 正方（m = n）：rank = n → 逆行列を持つ・det ≠ 0（正則）

前Chapterの 3×2 行列の場合、最大 rank = 2。
・ケースA（rank = 2） = フルランク → 2列が独立、像は ℝ³ の 2次元平面（健全）
・ケースB（rank = 1） = rank 不足 → 列が平行、像は 1次元直線（情報が潰れる）

直感：フルランク = 行列が"本気を出している"状態。サイズで許される最大の情報量を運んでいる。
rank 不足 = どこかで情報が潰れている（列同士が比例・行が同方向、など）。

感覚でつかむ：相関と rank 落ち（データサイエンス視点）

Last updated: 2026-07-23

行基本変形の手順に入る前に、rank が「落ちる／落ちかける」という現象を実データの肌感で押さえておく。行列の各列 = 1つの変数だと思うと、線形代数の rank とデータ分析の話がそのまま重なる。

設定：家賃を決める 4 変数
家賃を予測するのに、延べ床面積・坪数・駅からの距離・築年数 の4変数を並べる。
データ全体は 4 列の行列 → 見た目の次元は 4（rank 4 を期待）。
でも「その4本、本当に独立に効いてる？」を測るのが rank。

① 相関係数 = 1 → rank がきっちり1下がる

  • 延べ床面積（m²）と坪数は、単位換算しただけの完全に同じ動き（相関 = 1）。
  • 片方があればもう片方は定数倍で復元できる → 2本ある意味がなく、情報は実質1本。
  • 列が一次独立でなくなる = rank が 4 → 3 にきっちり1つ下がる。これはあなたの言う通り。

② 相関が高い（≠ 1）→ rank は落ちないが "落ちかける"

  • 理論（数学）：相関が 0.999 でも 1 ぴったりではないので、厳密には列は独立 → rank は 4 のまま落ちない。ここもあなたの感覚通り。
  • 現実（数値計算）：2本のベクトルがほぼ同じ方向を向いている状態。「独立ではあるが独立度がスカスカ」で、rank 落ち寸前の挙動をする。
  • この「厳密には落ちてないが実質潰れかけ」を、データ分析では マルチコ（多重共線性）／病的な行列（ill-conditioned） と呼ぶ。
まとめ（あなたの理解＝ほぼ完全正解）：
・相関 = 1　→ 完全な rank 落ち（逆行列が消滅・計算が崩壊）
・相関 ≈ 1（高）→ ほぼ rank 落ち（逆行列の値が暴走し、予測係数が激しくブレる）
rank は「独立な情報が何本あるか」のメーターなので、完全に潰れる場合だけでなく"似た方向を向いている" 冗長データも整理対象になる、という肌感が正しい。
補足：なぜ "近い" だけで暴走するのか
rank 落ちに近い行列 = det がほぼ 0。逆行列は det で割る操作を含むので、det ≈ 0 だと結果が 1/0 に近づいて発散気味になる。
→ だから「完全一致（相関1）」でなくても、近いだけで実務上は危険。この「det が 0 に近い＝潰れかけ」という尺度が、後の 固有値 や PCA の話にそのまま繋がる。

行基本変形と階段行列（rank の計算手順）

ここまでは rank を「列ベクトルの一次独立な本数」と概念的に定義してきたが、実際の計算では 行基本変形 で 階段行列 に変形して数える方法が標準。

行基本変形（Elementary Row Operations）

行列を扱いやすい形に変形するために許される3種類の操作。これらはrank・一次独立性・行が張る空間を一切変えないのがポイント。

  • ① 行の入れ替え：Rᵢ ↔ Rⱼ（i 行目と j 行目を交換）
  • ② 行のスカラー倍：Rᵢ → c·Rᵢ（c ≠ 0、ある行を 0 でない数で全体倍）
  • ③ 行に他の行のスカラー倍を足す：Rᵢ → Rᵢ + c·Rⱼ

なぜ rank を変えないか：3つの操作はすべて「行 が張る Span」を保存する。各行を入れ替えても、倍しても、別の行の倍数を足しても、3行が作る部分空間（Span）は不変。よって rank も不変。

  • ゼロ行（全部 0 の行）がある場合、それは一番下にまとめられている。
  • 非ゼロ行の先頭の非ゼロ要素（pivot / 主成分）が、上の行の pivot より必ず右にある。
  • pivot の真下は全部ゼロになっている。

  • 行列の正則性 — A が正則 ⇔ 行操作で I に到達できる

使い回しの一言：掃き出し法でやっている計算は、突き詰めると「基本行列 E₁, E₂, …, Eₖ を左から順に掛けて、A を整った形に持っていく」だけ。次の節以降の REF / RREF / 逆行列 計算は、すべてこの同じ操作の応用。

なぜ「影響がない」のか — 2D の幾何で見る

「3つの操作は解を変えない」と言われても、特に ③ R₁ → R₁ + c·R₂ は「式を勝手に足してるのに本当に大丈夫か?」と気持ち悪い。2変数で図に描くと一発で腑に落ちる。

舞台：2本の直線の交点を求める問題

R₁:  x + y = 3
R₂:  x − y = 1

解は (x, y) = (2, 1)。図で言えば 2本の直線が交わる点。各方程式は xy 平面の1本の直線、解はそれら全ての共通点。

① 入れ替え（R₁ ↔ R₂）

同じ2本の直線を、書く順番だけ変える。直線の集合自体は不変なので、当然交点も不変。説明不要。

② スカラー倍（R₁ → c·R₁、c ≠ 0）

例：R₁ を 2倍して 2x + 2y = 6 にする。

これは「x + y = 3」と完全に同じ直線。係数だけ違うが描かれる線は1本も動かない（両辺を同じ数で割れば戻る）。図形としての直線が同じなら、他の式との交点も同じ。"線そのものを書き換えていない"のがポイント。

③ 加算（R₁ → R₁ + c·R₂）— ここが本質

例：R₁ → R₁ + R₂ をやると、新R₁ は (x+y) + (x−y) = 3 + 1、つまり 2x = 4。

新R₁:  2x = 4  (縦線 x = 2)
R₂:    x − y = 1  (変わらず)

直線の傾きは全然違う（x+y=3 は右下がり、2x=4 は縦線）。なのに交点は依然 (2, 1)。なぜか?

幾何的直感：2本の元の直線の交点 (2, 1) は、両方の式を満たす点。だから両方の式をどう足し合わせても新しい式は必ず (2, 1) を通る。新R₁ は「元の交点を通る別角度の直線」に置き換わっただけ。
R₂ は変わっていないので、(新R₁) と R₂ の交点 = 元の交点。

代数で同じことを確認：(x, y) が元の連立を満たすなら R₁(x, y) = 3 かつ R₂(x, y) = 1。両辺を足せば R₁ + R₂ も自動的に満たす。つまり 元の解 ⇒ 新しい解。

解集合が 完全一致 する理由 — 可逆性

上の議論だけだと 元の解 ⊆ 新しい解 しか示せていない。「新しい連立にだけ満たされる別の解が湧いて出てないか?」を否定する必要がある。

鍵：3つの操作はすべて可逆。逆操作も「同じ3種類のうちのどれか」になっている。

操作 逆操作
① Rᵢ ↔ Rⱼ同じ ① Rᵢ ↔ Rⱼ（もう一度入れ替えれば戻る）
② Rᵢ → c·Rᵢ② Rᵢ → (1/c)·Rᵢ
③ Rᵢ → Rᵢ + c·Rⱼ③ Rᵢ → Rᵢ − c·Rⱼ

だから「元 → 新」の議論を逆向きにも適用できる：

  • 順方向：元の解 (a, b) は新しい連立も満たす（足し算で示せる）
  • 逆方向：新しい解 (a, b) は逆操作を1回かければ元の連立に戻るので、元の解でもある
元の解集合 ⊆ 新しい解集合  かつ  新しい解集合 ⊆ 元の解集合
 ⇒  2つの解集合は完全一致
レンズの比喩で：各方程式 = ターゲット (2, 1) にフォーカスを合わせている1枚のレンズ。3つの行基本変形は レンズの形（係数）を組み替えてもフォーカスは保つ "リフォーム" 操作。可逆だから、組み替え後のシステムを「逆リフォーム」して元に戻すこともでき、両者が映しているターゲットは完全に同じと言える。

高次元への拡張：n 変数なら「直線」は「超平面」に変わるだけで、ロジックはそのまま。各式 = 1枚の超平面、解 = 全部の共通点。3操作の可逆性とフォーカス保存性は次元に依らない。だから 何変数でも掃き出し法は解を変えない。

王道マイルストーン — どの順番で掃き出すか未履修

行基本変形は3種類の操作が許されているが、やみくもに使うと迷子になる。実際の掃き出し法にはほぼ機械的な「決まった順番」がある。これを王道マイルストーンと呼ぶ。型さえ覚えれば、3×3 でも 5×5 でも同じリズムで進む。

4ステップを繰り返すだけ

  • 1 左上 (1,1) を 1 にする（R₁ をスカラー倍）
  • 2 1列目の 1行目以外をすべて 0 にする（R₂, R₃, ... から R₁ の倍を引く）
  • 3 (2,2) を 1 にする（R₂ をスカラー倍）
  • 4 2列目の 2行目以外をすべて 0 にする（R₁ と R₃ から R₂ の倍を加減）
  • … 次の pivot (3,3) → 1、3列目の残りを 0 …… 対角線を右下に進みながら同じことを繰り返す
2 操作の対：「pivot を 1 に正規化」と「その列の残りを 0 に掃き出す」の2 つで1セット。pivot を左上から右下へ 対角に1マスずつ進めながらこのセットを繰り返すだけ。

厳密な定義 — Span が作る "縄張り" の完全一致

掃き出している途中で左側にゼロ行が出てしまうと、左を I にできない＝逆行列は存在しない。これは rank(A) < n（フルランクでない）と等価で、A が正則でないことを表す。

行列 A を「変換器」と読んだとき、関心の置きどころは2つに分かれる：出てくる側に注目するか、入る側のうち何が潰されるかに注目するか。

  • Image：「A で出せるもの全部」— 出力空間の中の届く範囲
  • Kernel：「A で潰されて消えるもの全部」— 入力空間の中の死角
具体例（3×3 で rank が落ちる行列）：例えば A が3列のうち2本しか独立でない場合、
  • ・Im A = ℝ³ の中の 2次元平面（rank = 2）
  • ・Ker A = 入力空間の中の 1次元の "潰れ線"（nullity = 1）

次元定理（Rank-Nullity Theorem）未履修

Image と Kernel は独立ではなく、入力空間の次元を分け合っているという関係がある。

rank(A) + nullity(A) = 入力空間の次元 n

直感：A は ℝⁿ の各次元を、「出力に届く」か「0 に潰される」かのどちらかに振り分けるだけ。中間はない。

読み方：
・rank が大きい ⇔ 多くの次元が出力に届く ⇔ 情報を保つ変換（極端：A が正則なら nullity = 0 で全部届く）
・nullity が大きい ⇔ 多くの次元が潰される ⇔ 情報を捨てる変換（極端：A = O なら全部潰されて rank = 0）

行列式（Determinant）
この章の位置づけ — カリキュラムの転換点：
ここから先（行列式 → 固有値 → 対角化）は、すべて V → V、つまり「空間を自分自身へ写す変換」の話。前半で扱った「V → W（別の空間へ移す）」とは舞台が変わる。
自分自身への写像（自己準同型）を深掘りするのがこの後のカリキュラムであり、その一歩目が行列式。det は「同じ空間に立ったまま、その変換が空間をどう拡大・反転・潰すか」を1数値で測る、自己写像を調べる最初の道具になる。

そもそも何の量か — 「変換が空間をどれだけ拡大・縮小するか」未履修

行列式 det(A) は、正方行列 A という変換が 面積・体積を何倍にするか を表す1つのスカラー。行列の "効き具合" を1数値に圧縮したサマリー。

幾何的な読み方：
・2×2 → 単位正方形が、変換後に面積 |det(A)| 倍の平行四辺形になる
・3×3 → 単位立方体が、体積 |det(A)| 倍の平行六面体になる
・符号（±）→ 向きが反転したかどうか（鏡像になると負）

記法：det(A) または |A|（縦棒。絶対値とは別物だが書き方が似ている）。詳しくは Notation タブの det(A) 参照。

落とし穴 — det が意味を持つのは「同じ空間への変換」だけ

det は「体積を何倍にするか」と説明したが、これは 入口と出口が同じ空間（V → V、いわゆる自己準同型 endomorphism）のときだけ成り立つ話。サイズが同じ正方行列なら det は計算できてしまうが、入口と出口が別の空間だと、その数値は「何倍」という意味を持たない。同じ次元 ≠ 同じ空間がポイント。

一言で：「次元が同じ（＝正方行列になる）」は det が計算できる条件にすぎない。det が不変量として意味を持つのは、入口＝出口で同じ目盛り（基底）を共有しているときだけ。

具体データで考える — カラムが違う3次元同士

どちらも「3次元データ」だが、軸（カラム）の意味がまったく違う2つの空間を変換する場合：

入口 V（3列）
・身長 [m]
・体重 [kg]
・年齢 [年]
— A →
出口 W（3列）
・年収 [万円]
・歩数 [歩]
・心拍 [bpm]

入口の「体積」は m · kg · 年、出口の「体積」は 万円 · 歩 · bpm。det はこの比だから、単位は

det の "単位" = (万円 · 歩 · bpm) / (m · kg · 年)

という意味不明な合成単位になる。「何倍に拡大した」と言える純粋な数（無次元）ではない。さらに —

決定的な問題：体重を kg → g に変える（×1000）だけで入口の体積が1000倍になり、det は 1/1000 に変わる。データ自体は同じなのに数値が動く ＝ 行列に固有の量になっていない。

なぜ同じ空間なら大丈夫か — 基底変換で見る

違いは「基底を変えたときに det がどう動くか」に現れる。

・同じ空間 V → V（自己準同型）：基底を変えると A → P A P⁻¹（入口と出口を同時に同じ P で取り替える）
  ⇒ det(P A P⁻¹) = det(P)·det(A)·det(P)⁻¹ = det(A)　… 目盛りを変えても不変 ✓

・違う空間 V → W：入口と出口をバラバラの基底で取り替えるので A → P A Q⁻¹（P ≠ Q）
  ⇒ det(P A Q⁻¹) = det(P)/det(Q) · det(A)　… 目盛りの取り方しだいでいくらでも変わる ✗
まとめ：det が「体積比」「正則かどうか」という行列固有の意味を持つのは、入口＝出口で同じ基底を共有する V → V のときだけ。だから 固有値・対角化（det(A − λI)）も、すべて同じ空間への変換を前提にしている。

det = 0 の意味 — 既習章との接続（rank・核・逆行列）未履修

det が 0 になるのは、変換が空間を潰してしまうとき。面積・体積が 0 に潰れる ＝ これまで学んだ「rank 落ち」「核がある」「逆行列なし」がすべて同じ現象の別の言い方。

逆行列（Inverse Matrix）
この章の位置づけ：
行列式で「変換が空間を潰すか（det = 0）／潰さないか（det ≠ 0）」を測れるようになった。潰さない変換なら、元に戻す変換が必ず存在する — それが逆行列 A⁻¹。
この章は「逆行列とは何か（巻き戻し）→ いつ存在するか（det ≠ 0）→ どう計算するか（2×2公式・余因子・掃き出し法）→ 性質と使い道」を1本につなぐ。ファイルの学習順では 行列式 → 逆行列 → 固有値 の中間地点。

そもそも何か — 「変換を巻き戻す」行列未履修

正方行列 A がベクトルを動かす変換だとすると、その動きを完全に元へ戻す変換が A⁻¹（A インバース）。掛ける順序に関係なく、往復すると「何もしない」＝単位行列 I に戻る。

A · A⁻¹  =  A⁻¹ · A  =  I
直感（undo）：A が「2倍に伸ばして45°回す」なら、A⁻¹ は「45°戻して 1/2 に縮める」。順に適用すると出発点に戻る。
重要な前提：逆行列は 正方行列（n × n）にしか定義されない。入口と出口が同じ空間（V → V）でないと「戻ってくる」という話にならないため。行列式と同じく自己写像の道具。

用語：逆行列を持つ行列を 正則（regular / 可逆 invertible / 非特異 nonsingular）、持たないものを 特異（singular）という。「正則 ＝ 逆が作れる ＝ 潰さない変換」はすべて同義。

逆行列が存在するかどうかは、これまで別々の章で見てきた条件とすべて同じこと。1つでも成り立てば全部成り立つ（＝正則の同値条件）。

固有値・固有ベクトル（Eigenvalue / Eigenvector）

そもそも何か — Av = λv が表すこと未履修

行列 A は「ベクトルを変換する装置」だった。多くのベクトルは A を掛けると向きも長さも変わる。
しかしごく一部の特別なベクトルは、A を掛けても向きが変わらず、長さが λ 倍になるだけで済む。

Av = λv　（v ≠ 0）

この関係を満たすとき、

  • λ（スカラー）を 固有値（eigenvalue）
  • v（ゼロでないベクトル）を 固有ベクトル（eigenvector）

と呼ぶ。eigen- はドイツ語で「固有の・それ自身の」。その行列に固有の、特別扱いされる方向という意味。

なぜ v ≠ 0 が条件か：v = 0 なら A0 = λ0 がどんな λ でも成り立ってしまい、情報がない。だからゼロでない方向だけを問題にする。

幾何的な意味 — 「変換しても傾かない方向」未履修

A を「空間を引き伸ばす・回す変換」と見ると、固有ベクトルはその変換で乗っている直線が回転せず、そのまま伸縮するだけの軸。

「傾かない軸」という感覚：平面全体を A で一斉に変換する場面を思い浮かべる。ほとんどのベクトル（矢印）は、伸び縮みするうえに向きも傾く — 変換前と後で、矢印の指す方向が別の線に移ってしまう。
ところが原点を通るある特別な直線だけは、変換しても同じ直線の上に乗ったままで、矢印はその線に沿って伸び縮み（または反転）するだけ。線そのものは一切かたむかない。この「かたむかない直線」の方向が固有ベクトル、そこでの伸縮率が固有値 λ。
直線が主役・矢印は脇役：固有ベクトルは長さではなく向き（直線）が本質。v が固有ベクトルなら 2v も 5v も −v も同じ固有ベクトル（同じ「かたむかない軸」を指すから）。だから求まるのは1本のベクトルではなく「1本の軸＝方向」で、教科書が代表として長さ1などに正規化しているだけ。
地球ゴマのたとえ：回っているコマや地球を思い浮かべると分かりやすい。表面のほとんどの点はぐるぐる動く（傾く）が、自転軸の上の点だけは動かない／軸の上に留まる。この自転軸にあたるのが固有ベクトル。3次元の回転を表す行列では、回転軸がちょうど λ = 1 の固有ベクトル（軸上は伸縮すらせず不動）になる。

λ の符号・大きさで、その軸の上で何が起きるかが決まる：

  • λ > 1 … その方向に引き伸ばす
  • 0 < λ < 1 … その方向に縮める
  • λ = 1 … その方向は不動（全く動かない）
  • λ < 0 … その方向に反転して伸縮（向きが逆になる）
  • λ = 0 … その方向は潰れて原点へ（核＝行列式 0 の話とつながる）
直感：「行列が何をする変換か」を理解する近道は、傾かない軸（固有ベクトル）と、その軸の伸縮率（固有値）を見つけること。これが分かれば、複雑な変換も「いくつかの軸方向の単純な伸縮」に分解して読める。
裏返し：「傾かない軸が1本もない」変換：平面の純粋な回転（90°回転など）は、どの方向の矢印も必ず傾けてしまう ＝ かたむかない軸が実数の世界に存在しない。だから実数の固有値・固有ベクトルを持たない（固有値は複素数になる）。「傾かない軸を探す」という感覚は、こうして軸が見つからないケースの理由まで一発で説明できるのが強み。
▶ 動かして体感する：固有ベクトルの流れ（アニメーション例題）
A=[[0.9,0.1],[0.1,0.9]] を (1,1)・(1,−1)・(2,0) などにかけ続けると、固有ベクトルは傾かず伸縮するだけ・それ以外はだんだん (1,1) 線へ吸い寄せられる様子が見える。λ=1 と λ=0.8 の違い＝「生き残る軸」と「縮む軸」を目で確認できる。

求め方の骨格 — 特性多項式 det(A − λI) = 0未履修

Av = λv を移項すると Av − λv = 0、つまり (A − λI)v = 0。
これが v ≠ 0 の解を持つ ためには、A − λI がベクトルを潰す（ランク落ちする）必要がある。すなわち：

det(A − λI) = 0

これを λ の方程式と見たものが 特性多項式（characteristic polynomial）。この根が固有値。手順はこう：

  1. det(A − λI) = 0 を解いて固有値 λ を求める
  2. 各 λ を (A − λI)v = 0 に戻し、その解空間（＝核）から固有ベクトル v を求める
章のつながり：行列式（det）と 核（Ax = 0 の解空間）が、ここで固有値計算の道具として直接効いてくる。具体的な計算例は今後この章に追加していく。

ショートカット — 三角行列の固有値は「対角線の数字」そのまま

上三角・下三角（対角も含む）行列は、対角線に並ぶ数字がそっくりそのまま固有値になる。det(A − λI) = 0 をわざわざ解く必要がない。試験や暗算で即答できる強力なショートカット。

なぜ成り立つか：A が上三角なら、A − λI も上三角のまま（対角から λ を引くだけ、下は 0 のまま）。
三角行列の det は対角成分の積（9章）だったので：
  det(A − λI) = (a₁₁ − λ)(a₂₂ − λ) … (aₙₙ − λ)
これが 0 になる λ ＝ 各因子を 0 にする値 ＝ λ = a₁₁, a₂₂, …, aₙₙ（対角成分そのもの）。

① 行列を「移動ルール」として読む

状態ベクトル x = [A店の客数, B店の客数] とすると、来年は x' = A x：

② 2つの固有ベクトルの「意味」

  • (1,1) ・ λ=1 ＝ 定常状態（50:50）：両店が同数のとき、流出10%と流入10%が釣り合い、来年も全く同じ。A(1,1)=(1,1)。λ=1 なので総数も減らずキープ。
  • (1,−1) ・ λ=0.8 ＝ 偏り成分：「A が多く B が少ない」というかたよりを表す方向。A(1,−1)=0.8(1,−1) なので、偏りは毎年 0.8 倍に薄れて消えていく。

ジョルダン標準形（Jordan Normal Form）

そもそも何のための話か

このChapter全体は、複雑な行列を「完璧に理解する」のではなく、「概要レベルで把握する」ための手法の話。

対角化・ジョルダン標準形は、要するに 行列の "サマリー" を抽出する技。
・固有値という最も本質的な情報だけ残して、面倒な細部を視界から消す
・5×5・10×10 のような直感の効かない行列でも、「これは何をする変換か」がざっくり掴める
・「完璧理解」と「無知」の間に置かれた、"概要理解" のための共通言語

つまり「ジョルダン形にできるなら、その行列の本質はもう掴んだも同然」というのが、線形代数の山頂で見える景色。以下、その背景と仕組みを順に見ていく。

モチベーション — 対角行列は理想、ジョルダン形は妥協

対角行列は計算が激安で理想形。しかし、すべての行列がそこまで綺麗には整理できない。

  • 対角行列に変形できる場合 → 対角化（Diagonalization）。最も美しい形。
  • 対角化できない行列もある — でも諦めない。「あと一歩だけ崩した形」までは必ず行ける。
  • その「妥協点・進捗形」が ジョルダン標準形。
Kyo の直感（ほぼ正しい）：対角行列（さらに言えば単位行列）は理想だが、そんなに美しく整理することは難しい。
とはいえ妥協点というか途中進捗として「中心の階段（対角）より左下を全部ゼロにできれば、本質はだいたい掴める」というのがジョルダン標準形。

形 — 対角＋すぐ上に 1、それ以外ゼロ

ジョルダン標準形は上三角行列の特別な形。「左下＝ゼロ」の進捗形に、もう一つ条件が乗る。

  • 対角に 固有値 λ が並ぶ
  • 対角のすぐ上（superdiagonal）に、ところどころ 1 が入る（同じ固有値が連続する箇所のみ）
  • それ以外（左下含む対角以外）はすべて 0

対角行列との関係

対角化可能 = ジョルダン標準形に 1 が一切入らない特殊ケース。つまり対角行列はジョルダン標準形の中で最もお行儀の良い部分集合。

形 構造 適用範囲
対角行列対角のみ非ゼロ、ほか全 0対角化可能な行列限定

包含関係：対角行列 ⊂ ジョルダン標準形 ⊂ 上三角行列。
対角に最も近づけた "汎用版" がジョルダン標準形。

何が嬉しいか

対角行列ほどではないが、ジョルダン形にしておくと多くの計算が劇的に楽になる。

  • 行列式：上三角なので対角成分の積（=固有値の積）
  • べき乗 Ak：ジョルダンブロックごとに公式で書ける
  • 行列指数関数 eA：線形微分方程式 ẋ = Ax の解析解に必須
  • 構造の見える化：固有値の重複度・固有ベクトルの不足を一目で把握できる
ジョルダン標準形の存在定理：複素数体上のすべての正方行列 A は、ある正則行列 P によって P-1AP = J（ジョルダン標準形）の形にできる。J は対角化が完璧にできるなら対角行列に、できないなら 1 が入る。

  • 固有値・固有ベクトル（Av = λv の意味と求め方）

01行列のサイズ・次元

「列数＝入力の次元、行数＝出力の次元」。積は内側の数が一致すれば定義でき、外側がサイズになる。

Q1

3×2 行列 A は、何次元空間から何次元空間への変換か。

解答・解説

列数 2 ＝入力、行数 3 ＝出力。よって R² → R³（次元を増やす変換）。

合言葉：「右から食べて、上に吐く」。掛ける相手のベクトルは下から入り（列数）、結果は縦に出る（行数）。

Q2

A が 2×3、B が 3×4 のとき、積 AB は定義できるか。できればサイズは。

解答・解説

内側 3 = 3 が一致 → 定義できる。外側を取って 2×4。

(2×3)(3×4) → 下線の内側が一致、外側 2 と 4 が残る。

Q3

A が 3×2、B が 2×2。AB と BA はそれぞれ定義できるか。

解答・解説

AB：(3×2)(2×2) → 内側一致 → 定義可・3×2。

BA：(2×2)(3×2) → 内側 2≠3 → 定義不可。

片方しか定義できないのが普通。これも非可換性の一因。

Q4

4×4 行列と 4×3 行列の積のサイズと、それが表す次元変換は。

解答・解説

(4×4)(4×3) → 4×3。列3＝入力、行4＝出力なので R³ → R⁴。
