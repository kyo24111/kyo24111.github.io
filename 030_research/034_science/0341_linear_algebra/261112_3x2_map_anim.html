行列の写像アニメ — 2D → 3D と 3D → 2D（Kernel）

A = [[1, 2], [3, 1], [0, 2]] に (x, y) = (1, 1) を入れると (3, 4, 2)。入力の平面（z = 0 に置いた ℝ²）が、A によって ℝ³ の中の斜めの平面（＝ Im A）へ移る様子を追う。

Last updated: 2026-11-12 ／ ② Kernel の例へ ／ 戻る：メインページ

① 3×2 行列 A で (1, 1) を写す — 2D → 3D

ドラッグで視点を回転。スライダーで任意の段階に止められる。
①入力 (1, 1) ＝ 1·e₁ ＋ 1·e₂（まだ平面 z = 0 の上）
②A を掛ける：基底の行き先は A の列。e₁ → (1, 3, 0)、e₂ → (2, 1, 2)。格子ごと斜めの平面へ。
③行き先も同じ組み合わせ：1·(1, 3, 0) ＋ 1·(2, 1, 2) ＝ (3, 4, 2)
a = 1·1 + 2·1 = 3　b = 3·1 + 1·1 = 4　c = 0·1 + 2·1 = 2

ポイント：出力は必ず2本の列ベクトルが張る平面（紫の面）の上に乗る。3D に出ても像は2次元のまま（rank 2）で、ℝ³ 全体には届かない。

② 2×3 行列 B で ℝ³ を ℝ² に押し込む — (6, −2, −5) は消え、(1, 1, 1) は残る

B = [[1, 3, 0], [2, 1, 2]]（①の A を転置したもの）。入力は ℝ³、出力は ℝ²（床の平面 z = 0 として描く）。(6, −2, −5) を入れると (0, 0) に消える ＝ このベクトルは Ker B に入っている。一方 (1, 1, 1) は (4, 5) に着地して残る。下のボタンで入力を切り替えられる。

ドラッグで視点を回転。紫の点線＝ Ker B（(6, −2, −5) の定数倍の直線）。
①入力 (6, −2, −5) ＝ 6·e₁ − 2·e₂ − 5·e₃（ℝ³ の中のベクトル）
②B を掛ける：基底の行き先は B の列。e₁ → (1, 2)、e₂ → (3, 1)、e₃ → (0, 2)。3D 空間が床（ℝ²）へ押しつぶされる。
③行き先も同じ組み合わせ：6·(1, 2) − 2·(3, 1) − 5·(0, 2) ＝ (6, 12) + (−6, −2) + (0, −10) ＝ (0, 0)。矢印が一周して原点に戻る。
1行目：1·6 + 3·(−2) + 0·(−5) = 6 − 6 + 0 = 0　2行目：2·6 + 1·(−2) + 2·(−5) = 12 − 2 − 10 = 0
①入力 (1, 1, 1) ＝ 1·e₁ ＋ 1·e₂ ＋ 1·e₃（ℝ³ の中のベクトル。Ker B の直線には乗っていない）
②B を掛ける：e₁ → (1, 2)、e₂ → (3, 1)、e₃ → (0, 2)。3D 空間が床（ℝ²）へ押しつぶされる。
③行き先も同じ組み合わせ：(1, 2) ＋ (3, 1) ＋ (0, 2) ＝ (4, 5)。原点には戻らない ＝ 消えずに残る。
1行目：1·1 + 3·1 + 0·1 = 4　2行目：2·1 + 1·1 + 2·1 = 5
ただし高さの情報（3D の 1 次元ぶん）は失われる：(1, 1, 1) を Ker 方向にずらした (7, −1, −4) も (−5, 3, 6) も、同じ (4, 5) に着地する。

Kernel として読む

・Ker B を求める：x + 3y = 0、2x + y + 2z = 0 → x = −3y、z = 5y/2 → y = −2 と置くと (6, −2, −5)。Ker B ＝ この方向の直線（1次元）。
・次元定理：rank B = 2（出力は ℝ² 全体に届く）＋ nullity B = 1 ＝ 3（入力の次元）。3 次元のうち 1 次元ぶんが消える。
・なぜこの方向？：Bv = 0 は「v が B の各行 (1, 3, 0) と (2, 1, 2) の両方と内積 0」という意味。つまり Ker は行ベクトルの両方に直交する方向。実際 (1, 3, 0) × (2, 1, 2) ＝ (6, −2, −5)（外積）。
・Kernel 方向にずらしても出力は変わらない：B(1, 0, 0) = (1, 2)、B(7, −2, −5) = (1, 2)。違う入力が同じ出力に重なる ＝ B には逆行列がない（情報が消える）。

①と並べると：A（2D → 3D）はKernel が {0} で何も消えないが、像は平面止まり（ℝ³ 全体に届かない）。B（3D → 2D）は像が ℝ² 全体に届くが、Kernel の直線 1 本ぶんが消える。
