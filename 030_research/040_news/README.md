# News Curation — 指示集

Kyoが「読みたくなる」ニュースを集めるためのルール。指示が来るたびに追記する（日付つき）。

## 対象テーマ
- 製鉄（steel / steelmaking）
- データセンター
- ロボティクス（robotics）
- ミネラル（非鉄）— 主役は**アルミニウム・銅**
  - 候補（Kyoの採否待ち）: レアアース(NdPr) / ガリウム・ゲルマニウム / アンチモン・タングステン / リチウム・ニッケル
- 冷却（cooling）— ニッチ枠。新しいネタが少ないので数ヶ月前まで遡ってOK

## 選定の優先順位
1. **新しいスタートアップの勃興**（ベスト）— 新規調達・新プレイヤー登場
2. **日本の大企業 × USの急成長企業**のコラボ・出資（かなり嬉しい）
3. 大企業との関連（出資・オフテイク・提携）はポジティブに扱う
4. deeptechなテックアジェンダもOK

- 地域: **USスタートアップ中心**、日本もOK
- 著名人のコメントがあれば添える（a16z・Sequoiaのパートナー、US著名人など）。誰が何と言ったか＝見もの

## フォーマット
- テーマごとに3本
- 1本あたり2〜3行のサマリ
- 末尾にソースURL
