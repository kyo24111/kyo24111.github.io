01News Summary

ロボットの「教材」を作る会社に、Sequoia・NVIDIA・Microsoft・Samsungが揃った

Mecka（mecka.ai）は2026年10月7日、$60MのSeries Bを発表した。リードはSequoia Capital。新規でNVIDIA、M12（Microsoftのベンチャーファンド）、Qualcomm Ventures、Samsungが入り、既存のKindred、Framework Ventures、Neoも継続した。

事業は、人間が身体センサーやスマートフォンを着けて洗濯物をたたむ・コーヒーを淹れる・修理するといった作業を行い、その記録をモーション／3D／手指の姿勢データに加工してロボット企業に売ること。さらに最近は、ハード・現場でのデータ収集・モデルのpost-training・システム統合・運用までを一括で請け負う「modern robotics integrator」を名乗っている。

資金使途は3つ：①データ基盤のスケール ②社内リサーチラボの強化 ③商用ロボット導入の拡大。データ会社から、データを持ったままロボットを現場に入れる会社へ — という転換を資金調達で明言した形。
表記の注意
  • 評価額：会社は非開示。約$500Mという数字はTechCrunch報道を引いたもので、会社は確認していない。
  • $100Mの中身：Series B発表では「2026年6月にrun-rate revenue $100M超」。一方、6月のSeries A報道（AI Business等）では「署名済み契約ベースで$100M ARRを見込む」という表現だった。実売上の年換算か、契約ベースの見込みかで表記が揺れている。
  • 拠点：New York（AI Business）／Toronto＋New York（TFN）。KindredはNew York・Toronto・Shenzhenでの運営と記載。

04What Mecka Does

テレオペではなく「人間がそのままやる」

ロボットの学習データを作る主流の方法はテレオペレーション（人がロボットを遠隔操作して動かし、その操作ログを教師データにする）。正確だが、ロボット1台につき1人が張り付くため遅くて高い。Meckaはこれと決別し、人間が自分の体で作業する様子を直接記録する。

1
収集デバイス
自社設計の身体センサー・触覚グローブと、市販のiPhoneを分散型の記録装置として組み合わせる。参加者は報酬を受け取って日常作業を記録する。
2
記録するもの
頭部／手持ちリグからのRGB-D映像、手首の6自由度姿勢、指の関節、接触イベントと把持力、視線、IMU。ミリ秒単位で同期。
3
加工
社内ラボでモーショントラッキング、3D再構成、手指姿勢推定（誤差±1cm）に変換。合成データ生成や評価サービスも提供。
4
導入（integrator）
企業向けに、ロボットのハード調達・現場でのデータ収集・モデルのpost-training・システム統合・継続運用を一括で提供。導入後もデータを取り続けて性能を上げるのが従来型SIerとの違い。
研究面の裏付け。Meckaは一人称視点の人間デモから学ぶ研究コンソーシアムEgoVerseに参加している。EgoVerseの研究では「人間データは多いほどロボットの方策性能は概ね上がる」一方、学習目的とデータを合わせることが重要とされる。量を集めるだけでは足りない、という但し書きつき。

09Bull / Bear

強気と弱気

論点BullBear
データテレオペより桁違いに安く・速く・多様なデータが取れる。モデル会社が増えるほど需要が増える「つるはし売り」人間とロボットの体の違いで、そのままでは使えない。モデル側が強くなると必要なデータ量自体が減る可能性

10Implications

示唆

Takeaways

① フィジカルAIでも「つるはし売り」に資金が来ている。LLMでScale AIやSurgeがデータ供給で巨大化したのと同じ構図が、ロボットで始まっている。モデル（Skild）とデータ（Mecka）の両方にSequoiaが入っているのは象徴的。

② データ会社 → integrator という進化。データを売るだけでは単価もロックインも弱い。現場に入って導入・運用まで握り、そこでデータを取り続ける。AIコンサル→実装→運用でデータを溜めるという流れは、Wanderlustの事業の作り方とも重なる。

③ 創業者はAI研究者でなくてよい。決済・現場オペレーション出身の4人が、40名で$100M run rateを作った。フィジカルAIの勝ち筋は「研究」だけでなく「人と現場を動かす力」にもある。ハードインフラ系の次事業を考える上での参考になる。

④ 日本の現場はデータ供給地になりうる。標準化された作業（飲食・介護・物流）と丁寧な作業者が揃う日本は、人間デモデータの質で優位を持ちうる。Skildが日本のカフェで稼働しているのと同じく、日本は買い手ではなく学習データの産地として組み込まれていく可能性がある。

11Q&A

用語と論点

テレオペレーション（teleoperation）とは？なぜ避けるのか？

人がVRヘッドセットやコントローラーでロボットを遠隔操作し、その操作ログ（カメラ映像＋関節の動き）を教師データにする方法。ロボット自身の体で取ったデータなのでそのまま学習に使えるのが最大の利点。
ただしロボット1台につき操作者が1人必要で、1時間のデータに1時間以上かかる。機体も高価で台数を増やしにくい。Meckaは「人間がそのまま作業してiPhoneとセンサーで記録する」ことで、機体なしで並列に大量のデータを集める。

embodiment gap（体の違い）はどう埋める？

人間の手は指5本・関節20以上、ロボットのハンドは2本指のグリッパーだったりする。人間の動きをそのままロボットの関節角に写しても動かない。
対策は、手首の位置や把持のタイミング、接触の有無など体に依存しにくい情報を学習に使うこと、そして少量のロボット実機データで最後に合わせ込むこと（post-training）。Meckaが手首6自由度・接触イベント・把持力を細かく取っているのはこのため。

EgoVerseとは？

一人称視点（egocentric）の人間デモからロボットを学習させる研究のコンソーシアム。Meckaも参加している。
研究結果としては「人間データを増やすとロボットの性能は概ね上がる」一方で、「何を学ばせたいかとデータの中身を合わせること」が重要とされる。量を売るだけのデータ業者は差別化しにくく、どの作業のデータをどう取るかの設計力が価値になる、という示唆でもある。

robotics integrator（ロボットSIer）とは？

ロボットの機体を選び、工場や店舗の設備・システムと接続し、現場で動くようにする会社。日本でいう「ロボットSIer」。従来は導入したら終わりのプロジェクト型ビジネスだった。
Meckaが「modern」を名乗るのは、導入後も現場でデータを取り続け、モデルを更新して性能を上げ続けるから。導入＝データ収集拠点の設置、という発想。

run rate はどこまで信用していい？

run rateは「直近1ヶ月（や四半期）の売上×12」の年換算値。ARRは本来、継続契約に基づく年間経常収益。
Meckaの場合、6月のSeries A時点では「署名済み契約で$100M ARRを見込む」という表現で、10月には「6月に$100M run rate超」となっている。データ案件はラボの予算に応じた単発の大型契約になりやすく、年換算すると大きく見える点に注意。実際の通期売上や更新率が出るまでは、見込みとして読むのが妥当。

なぜ大手テック（Magnificent Seven）がデータを買うのか？

Tesla（Optimus）、NVIDIA（GR00T）、Google（Gemini Robotics）、Amazon（倉庫ロボット）、Meta（研究）など、Magnificent Sevenのほぼ全社がロボットの基盤モデルを開発している。LLMではインターネット上のテキストが学習データになったが、ロボットの動きのデータはネット上にほとんど存在しない。
そのため、お金を払ってでも作ってもらうしかない。ここがMeckaのような会社の市場になっている。どの企業が顧客かは非開示。
